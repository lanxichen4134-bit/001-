# 澜心社女性身体状态测评 1.0

> 定位：新用户首次身体状态初测档案，用于健康教育、运动课程分流、健康顾问咨询分流和用户身体画像沉淀。

## 一、产品目标

这套测评不做医疗诊断，也不输出单一“健康总分”。它用于完成：

1. 建立用户基本身体档案；
2. 形成身体成分、体型曲线、体态核心、盆底状态四类身体画像；
3. 将用户分流到自主练习、课程推荐、健康顾问咨询或专业评估建议；
4. 将结构化标签沉淀为后续用户研究和课程迭代的数据基础。

## 二、核心用户路径

`开始测评 → 基本身体档案 → 身体成分 → 体型曲线 → 体态与核心 → 盆底功能自测 → 安全确认 → 身体目标 → 生成身体画像 → 课程/顾问分流`

风险分流：

- GREEN：可直接进入普通自主练习；
- YELLOW：推荐课程，可咨询健康顾问；
- ORANGE：优先健康顾问咨询，再确定训练顺序和强度；
- RED：暂停普通自动强化训练推荐，建议进一步专业医疗/盆底康复评估。

## 三、测评题库

### 1. 基本身体档案

**1. 你的年龄**（必填）
- 选项：25岁以下 / 25–29岁 / 30–34岁 / 35–39岁 / 40–44岁 / 45–49岁 / 50–59岁 / 60岁以上

**2. 你目前处于哪个生命阶段？**（必填）
- 选项：未生育 / 备孕期 / 孕期 / 产后6周以内 / 产后6周–1年 / 产后1–3年 / 产后3年以上 / 围绝经期 / 绝经后

**3. 你的生育次数**（必填）
- 显示条件：`{"field": "lifeStage", "notIn": ["NULLIPAROUS", "PRECONCEPTION"]}`
- 选项：未生育 / 1次 / 2次 / 3次及以上

**4. 你的生产方式**（选填）
- 显示条件：`{"field": "parity", "notIn": ["0", null]}`
- 选项：顺产 / 剖宫产

**5. 身高（cm）**（必填）
- 数值范围：130–200

**6. 体重（kg）**（必填）
- 数值范围：30–200

**7. 腰围（cm）**（必填）
- 数值范围：45–180

**8. 臀围（cm）**（必填）
- 数值范围：60–200

**9. 你知道自己的体脂率吗？**（必填）
- 选项：不知道 / 知道

**10. 体脂率（%）**（选填）
- 显示条件：`{"field": "bodyFatKnown", "equals": "YES"}`
- 数值范围：5–60

### 2. 体型曲线分析

**1. 哪一种最像你现在的身体？**（必填）
- 选项：A型｜下身集中型 / H型｜直线型 / O型｜腰腹集中型 / V型｜上宽下窄型 / X型｜曲线型

**2. 你最想改变哪些地方？**（必填）
- 选项：小腹突出 / 腰粗/没有腰线 / 骨盆视觉宽 / 臀部扁平 / 臀部下垂 / 大腿粗 / 手臂松 / 背部厚 / 胸型/上半身体态 / 整体松垮
- 最多选择：5项

### 3. 体态与核心

**1. 下面哪些情况比较像你？**（必填）
- 选项：头容易向前伸 / 圆肩/含胸 / 高低肩明显 / 肋骨容易向前翻 / 小腹经常向前顶 / 腰弧明显、屁股后翘 / 左右骨盆/臀线不一样高 / 膝盖锁死、X/O型腿或足弓塌陷 / 没有明显感觉/不确定（互斥选项）

**2. 平时呼吸时，你更容易感觉哪里在动？**（必填）
- 选项：胸口 / 肩膀 / 腹部 / 腰背 / 不知道

**3. 做腹部或盆底训练时，你是否经常憋气？**（必填）
- 选项：经常 / 偶尔 / 很少 / 不确定

### 4. 盆底功能自测

统一量表：0=从不/没有；1=偶尔/轻微；2=经常/明显；3=几乎每次/非常明显。

**1. 咳嗽、打喷嚏、跳跃或跑步时会漏尿吗？**（必填）
- 评分：0–3

**2. 是否会突然特别想尿，甚至来不及去厕所？**（必填）
- 评分：0–3

**3. 夜里通常需要起来小便几次？**（必填）
- 选项：0次 / 1次 / 2次 / 3次及以上

**4. 是否有排尿启动困难，或尿完仍觉得没有排干净？**（必填）
- 评分：0–3

**5. 久站、运动或一天结束时，下腹/会阴是否有坠胀感？**（必填）
- 评分：0–3

**6. 是否感觉阴道内有东西向下坠或有突出感？**（必填）
- 选项：没有 / 偶尔 / 经常 / 明显感觉到突出

**7. 是否经常便秘，排便需要明显用力？**（必填）
- 评分：0–3

**8. 是否有控制不住排气或大便的情况？**（必填）
- 评分：0–3

**9. 平时是否有会阴、阴道口、尾骨或盆腔区域紧绷/疼痛？**（必填）
- 评分：0–3

**10. 亲密活动或置入时是否有明显紧张、疼痛或难以放松？**（必填）
- 选项：没有 / 偶尔 / 经常 / 因此避免亲密活动/置入

**11. 轻轻收缩盆底时，你能感觉到盆底向内、向上提起吗？**（必填）
- 选项：很明显 / 有一点 / 不确定 / 完全找不到

**12. 轻轻收紧后，你能够完全放松吗？**（必填）
- 选项：可以 / 有一点困难 / 很难 / 不知道什么叫放松

**13. 轻轻收缩盆底时，你是否会同时出现这些情况？**（必填）
- 选项：憋气 / 收紧臀部 / 夹大腿 / 腹部猛烈收紧 / 肩颈用力 / 都没有（互斥选项） / 不确定

**14. 轻轻收紧盆底后，能否自然呼吸并保持约3–5秒？**（必填）
- 选项：可以 / 约2–3秒 / 很快就掉 / 不确定/无法做到

**15. 这些身体问题目前对你的生活影响有多大？**（必填）
- 范围：0–10

### 5. 安全确认

**1. 近期是否存在以下情况？**（必填）
- 选项：原因不明的阴道异常出血 / 血尿 / 明显无法正常排尿 / 明显阴道/盆腔器官脱出感 / 持续或明显加重的盆腔/会阴疼痛 / 明显粪便失禁 / 近期正在手术恢复期 / 以上都没有（互斥选项）

### 6. 我的目标

**1. 你现在最想优先改善什么？**（必填）
- 选项：减脂 / 增肌 / 腰腹核心 / 腰臀曲线 / 体态 / 盆底功能 / 体能与活力 / 整体身体状态

## 四、关键算法与产品规则

### 1. 身体成分

- BMI = 体重(kg) ÷ 身高(m)²；
- 腰臀比 = 腰围 ÷ 臀围；
- 输出 BMI、腰围、腰臀比、体脂率参考等级；
- 体脂率仅作产品参考，不作为医学诊断依据。

### 2. 盆底功能分类

系统至少区分：

- BALANCED｜平衡/维持型
- WEAKNESS｜偏弱型
- TENSION｜偏紧张型
- COORDINATION｜收放协调不足型
- MIXED｜混合型

核心原则：**先判断能不能收、能不能放、是否存在代偿和症状风险，再决定是否进入强化训练。**

### 3. 结果页

结果页不显示单一总健康分，固定呈现四张卡：

1. 身体成分；
2. 身体曲线；
3. 体态核心；
4. 盆底状态。

同时给出“现在最值得先做的3件事”，并正常只推荐“1个主计划 + 最多1个辅助计划”。

### 4. 安全边界

以下情况优先进入 RED 或专业评估路径：

- 原因不明的阴道异常出血；
- 血尿；
- 明显无法正常排尿；
- 明显阴道/盆腔器官脱出感；
- 持续或明显加重的盆腔/会阴疼痛；
- 明显粪便失禁；
- 评分规则中定义的其他高风险条件。

孕期、产后6周以内、近期手术恢复期不直接进入普通强化训练路径。
