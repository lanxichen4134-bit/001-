# Inbox｜先接住，再整理

这里承接尚未判断去向的原始灵感、语音转写、聊天片段、微信复制、阅读触发和日常观察。速度优先，原话优先；不要在刚记录时逼自己分类或写成长文。

## 建档模板

~~~markdown
---
title: 一句话标题或待命名
type: 语音转写 / 原始文字 / 日常观察 / 用户线索 / 阅读触发
tags: []
source: 澜心本人 / 已去标识化来源
created_at: YYYY-MM-DD
status: raw_idea
privacy: public-safe / internal-only / 待判断
---

# 原话｜禁止覆盖

保留原始表达；转写不确定处标 [待核]，不要脑补。

# AI理解｜可以更新

- 触发点：
- 可能的核心问题：
- 可关联的旧素材：
- 需要补的事实、授权或论据：
- 建议下一步：讨论 / 继续观察 / 进入选题卡 / 不处理
~~~

## 硬规则

- 原话与 AI 理解必须分区；AI 不能用润色版替换原话。
- 学员、客户、家人或健康信息默认去标识化；原始语音、聊天、影像和身份信息不提交到公开仓库。
- 一条灵感不是长期价值观。重复出现、补足语境和证据后，才可提出“建议写入 Brain”。
- 整理完成后，正文进入最合适的唯一主位置；Inbox 留链接或处理记录，不复制正文。
