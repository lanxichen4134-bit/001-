# 重要决策

## D-001｜项目唯一提交远端

- 日期：2026-08-14
- 决定：本项目只提交到 https://github.com/lanxichen4134-bit/001-.git 的 main 分支。
- 背景：本次最新明确用户指令覆盖旧执行 Prompt 中指向 obsidian.git 的远端约定。
- 影响：旧 Obsidian Vault 仅作为本次 Brain 的只读资产来源；不得自动向其写入或推送。

## D-002｜不复制旧知识库

- 日期：2026-08-14
- 决定：V0.1 建立紧凑的 Brain、索引和同步快照，不搬运旧 Vault 的研究正文、原始资料或完整内容库。
- 原因：一份正文只有一个主位置；降低隐私、重复和版本分叉风险。

## D-003｜公开仓库安全边界

- 日期：2026-08-14
- 决定：目标远端经核验为公开仓库，因此只提交公开安全的、去标识化文本。
- 不提交：Token、密码、访问链接、原始聊天、语音/人脸、学员或家庭可识别资料、健康档案、未公开经营数据、私钥和大文件原件。

## D-004｜定位版本优先级

- 日期：2026-08-14
- 决定：以已有《澜心IP定位与表达准则》标注的 2026-08-14 当前主版本作为本 Brain 的定位基线。
- 影响：采用其已明确的四个内容支柱和占比；旧 Prompt 中的两支柱描述仅作为历史输入，不另建冲突版本。

## D-005｜内容状态唯一链路

- 日期：2026-08-14
- 决定：统一使用 raw_idea → discussing → idea_clear → structure_ready → drafting → approved → published → reviewed。
- 影响：Inbox、Content 和 Reviews 不另发明并行状态系统。

## D-006｜视频内容档案以文本事实和双 ID 跨设备关联

- 日期：2026-08-24
- 决定：原始视频、音频、剪辑工程与平台后台截图不进入公开 GitHub；GitHub 保存脱敏的视频内容档案、三层逐字稿、发布数据快照与复盘。Content ID 是一条内容的唯一主键；Publish ID 是一次平台发布的唯一主键。
- 影响：同一内容跨平台发布不得重复建立 Content；数据按新增 Snapshot 追加、不覆盖历史值。原始媒体由 iCloud、NAS、网盘或其他受控媒体资产系统跨电脑管理，不记录本机绝对路径。
- 边界：视频转写、评论、数据和单条复盘中的候选原话或洞见不自动升级 Brain，须澜心明确确认；公开仓库只提交 public_safe 的公开安全文本。

## D-007｜国际医学证据研究路径

- 日期：2026-09-04
- 决定：停止将个人 NEJM 跨境订阅作为课程研发的主路径。采用“PubMed 自动检索与国际指南发现 → 开放获取优先 → 中国大陆合规的按篇文献传递补足全文 → 发布前分层核验”的研究路线。
- 背景：本次个人订阅未形成成功订单；单一期刊也不能覆盖女性身体、盆底、性健康与生命周期的全部研究需求。
- 影响：不再重复个人跨境结算；不把 NEJM 医学前沿当作 NEJM 英文全文订阅，也不将其内容直接复制到课程或公开素材。只有在持续项目确实被全文访问瓶颈阻塞时，才评估合法机构许可；所有来源仍遵守公开仓库 `citation_only` 与医学边界规则。


## D-008｜一句话入口与三类工具协作

- 日期：2026-10-19。
- 依据：澜心本轮《AI内容工作系统基础框架升级任务》明确授权施工与公开安全文件正常提交推送；V2两份方案和报告模板作为方法参考，附件中的历史安排不自动成为本轮执行命令。
- 确认原则：①Chat为主要入口和中控；②Work承接真实研究及多步骤任务；③Codex负责系统建设、知识管理和版本；④唯一仓库保持001-的origin/main；⑤Obsidian为辅助只读来源；⑥自然语言一句话启动；⑦外部需求和自身素材双路径并行；⑧研究衔接文案与脚本；⑨完整业务判断逻辑向澜心可见；⑩个性化写作规则逐步补充，未确认不长期固化。
- 落点：ONE_SENTENCE_EXECUTION、SYSTEM_MAP、RESEARCH_REPORT_STANDARD和现有Prompts/Content入口。跨环境不预设共享权限，交接说明与实际发送、执行、回执分开记录。规则建成不等于工具已联通。

- 状态约束：S1—S6只作研究证据层级，不替换D-005内容状态；不与Brain原话的说话人确认等级S3混用。P0/P1/P2不新增为内容状态；旧视频SOP的P0—P3仍仅为剪辑问题优先级。

- 来源边界：本轮只实际读取用户给出的两份V2 DOCX和Markdown模板，未读取其引用的原录音、截图、Drive报告、旧总控机制或平台规则原文；不能继承“本轮已核验”身份。
