正式任务开始时，核 main 和相关主件。源改动后用现有生成器重建、核对来源 SHA256，记为待上传。上传后由目标 Project 重新打开或下载验证，才记为该端已同步。私库更新时仅按具体任务更新公开摘要或索引。开展平台研究时继续区分 YouTube V1.2 的六份试读稿、两份长课笔记及小红书 V2.1 的有限采样，实际试读、审校、扩量和发布各自凭回执认定。
