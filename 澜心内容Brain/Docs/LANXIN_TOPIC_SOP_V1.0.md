# 澜心1.0选题SOP

> 适用范围：30+女性身心健康IP的公域内容生产、直播切片、短视频、早课选题及商业承接。
> 
> 核心目标：不是生产更多标题，而是持续找到“用户此刻最关心的问题 × 澜心最有资格讲的话 × 能自然进入业务闭环”的交叉点。

## 1. 内容总目标

澜心内容不以单纯追求播放量为终点，而要同时完成四件事：

1. 流量：让精准女性停下来。
2. 信任：让用户知道澜心有长期专业、经历和判断。
3. 用户教育：让用户重新理解自己的身体、关系和人生问题。
4. 商业承接：自然进入训练、课程、产品、线下服务和长期陪伴。

业务闭环：

公域看见 → 产生共鸣 → 建立专业信任 → 形成身体体验 → 进入课程/训练 → 持续陪伴 → 产品/线下服务/高阶课程。

## 2. 四大内容母题

### 2.1 身体的主人｜40%

气血、精力、睡眠、疲劳、盆底、核心、呼吸、腹部、体态、肌肉、减脂塑形、月经、生育、产后、小产后恢复、围绝经期、更年期、身体觉察、内感受、神经系统、身体与情绪。

### 2.2 思想的主人｜25%

年龄焦虑、身材焦虑、女性价值、成功女性、女性力量、自我选择、爱的匮乏、身体客体化、女性为什么越来越累、拥有越来越多却不一定幸福。

核心方向：从“别人怎么看我”回到“我怎么看我自己”。

### 2.3 关系与亲密｜20%

性、性欲、性感知、亲密关系、婚姻、女强男弱、爱与尊重、边界、依恋、取悦、母女关系、亲子关系。

原则：性感不庸俗。性不是猎奇或技巧堆砌，而是女人与身体、欲望、边界和关系的连接。

### 2.4 女性成长｜15%

女性创业、中年重启、母亲身份、成熟女性、放手、事业、财富、成长、领导力、自我实现、40+人生、旅行与生命体验。

此类内容重点建立“澜心这个人”，而不只是“澜心老师”。

## 3. 选题五道门（100分）

### 3.1 用户需求强度｜30分

判断问题：这个女人现在真的关心吗？她疼不疼、急不急、怕不怕、想不想解决、会不会停下来？

优先关键词：瘦、老、累、睡不好、月经、更年期、小肚子、漏尿、松弛、疼痛、没有性欲、没感觉、情绪、气血、婚姻、爱、身体变化。

原则：不要从“知识重要”出发，要从“用户觉得和自己有关”出发。

### 3.2 认知张力｜20分

标准结构：

你以为A → 其实还可以再往里看一层 → 为什么 → 新认知 → 怎么做。

认知冲突不是故意唱反调，而是指出旧认知在哪些条件下失效，并给出新的判断边界。

示例：
- 你以为减肥就是少吃多动；40岁以后还要看肌肉、睡眠、压力、激素环境和恢复能力。
- 你以为盆底越紧越好；真正健康的盆底是该收时能收、该松时能松。
- 你以为没有性欲只是年龄大了；很多女人失去的可能首先是身体感觉。

### 3.3 澜心身份匹配度｜20分

至少回答：为什么这件事由澜心来讲更有价值？

优先依据：
- 我教过：长期教学与学员观察。
- 我经历过：女性、妈妈、创业者、中年女性的人生经验。
- 我长期研究过：女性身体、盆底、身心、性、女性成长。
- 我有真实案例：课程、训练、线下服务中的可公开案例。
- 我形成了自己的判断：不是搬运，而是事实 + 澜心理解。

一个题很热，但与澜心的专业、经历、案例、长期观察和独特判断都没有连接，原则上不追。

### 3.4 证据与内容厚度｜20分

内容必须主动区分四类信息：

A. 科学事实：研究、医学指南、政策、统计。
B. 专业共识：行业指南、专家共识、临床实践。
C. 澜心长期观察：必须表达为“我过去十几年教学里观察到……”，不能包装成普遍规律。
D. 澜心观点：用“我的理解是……”“我越来越觉得……”等方式明确标识。

纪律：事实是事实，经验是经验，观点是观点，不得混淆。

### 3.5 时机｜10分

关注政策、平台窗口、社会事件、季节、节日、女性健康热点、明星事件等。

原则：只借热点，不追热点。热点只是入口，最后要回到女性身体、心理、关系或选择。

## 4. 一票否决项

出现以下情况原则上直接淘汰或退回：

1. 与精准女性用户无关，只有泛八卦。
2. 和澜心身份没有连接。
3. 只有情绪口号，没有判断。
4. 只有专业，没有用户场景和传播表达。
5. 医疗健康表述越界，出现根治、治愈、保证、必然有效、疾病逆转等不当承诺。
6. 为流量走性猎奇、低俗擦边或身体羞耻路线。
7. 无来源却使用强结论。
8. 把相关说成因果、把可能说成必然、把个案说成普遍规律。

## 5. 六大选题来源池

### A池｜真实用户问题（最高权重）

来源：直播评论、私信、社群、课程提问、打卡、小程序反馈、线下学员、医院用户、门店顾客。

要求：尽量保存用户原话，不要过度概括。

### B池｜澜心本人素材

来源：早课即兴分享、旅行感受、女性身份体验、创业、母亲、关系、身体练习、教学感悟、学习笔记、临场金句、朋友聊天、咨询发现。

触发词：“我突然发现……”“我最近越来越觉得……”“过去我以为……”。

### C池｜课程与案例库

来源：长期教学、学员案例、课程逐字稿、训练营、早课、线下班、女性健康项目。

原则：案例用于把专业知识放回真实人生，不冒充普遍规律。

### D池｜专业研究

重点：女性医学、盆底、更年期、内分泌、性医学、神经科学、内感受、身体心理学、运动科学、生殖健康、睡眠、肌肉、骨骼、身心医学。

目的：不是搬论文，而是回答“这个证据能解释女人生活里的什么问题？”

### E池｜社会热点

热点重新过“女性视角”，避免复述事件本身。

### F池｜竞品与市场

观察视频号、抖音、小红书、B站、播客及同赛道账号。

原则：不复制观点，只研究市场正在为什么停留。

## 6. D-E-I-T-H内容生产流水线

### D｜Discover 找题

每周生成30—50个候选，不要求全部拍。

每条候选必须带“选题身份证”：
1. 原始材料
2. 用户问题
3. 选题标题
4. 核心冲突
5. 目标用户
6. 澜心为什么能讲
7. 证据来源
8. 内容价值
9. 商业连接
10. 风险
11. 推荐形式
12. 五项评分

### E｜Evaluate 选题

从候选中筛Top10，再组成实际生产组合。

建议每周内容结构：
- 精准流量题：解决“为什么停下来”。
- 认知长青题：解决“为什么关注澜心”。
- 人格价值题：解决“为什么喜欢和信任澜心这个人”。
- 商业承接题：解决“为什么应该继续跟着澜心练/学/体验”。

参考比例：40%精准流量、30%专业认知、20%人格价值、10%直接承接。

注意：商业承接不等于硬广，所有内容都可隐性连接业务，但不能牺牲内容价值。

### I｜Insight & Script 结构与脚本

禁止AI拿到标题后一步写全文。

先交：事实清单 + 结构提纲，再进入逐字稿。

澜心常用结构：

具体生活场景 → 误区 → 再往里看一层 → 专业/身体/心理机制解释 → 重新理解自己 → 一个可执行动作 → 一句金句。

专业解释控制在1—3个核心知识点，避免讲成课堂。

公域内容要完成至少一次“小交付”：让用户听懂一个问题、学会一个判断、做一个动作或产生一次身体体验。

### T｜Talk Like Lanxin 澜心人话化

不是简单口语化，而是变成澜心会说的话。

语言特征：
1. 像聊天：“你有没有发现……”“很多女人会有这种感觉……”。
2. 不端着，研究和专业知识要马上翻译成人话。
3. 专业术语之后立即接生活感受。
4. 经常从身体进入人生：盆底→松弛能力，呼吸→控制与放松，肌肉→女性力量，内感受→找回自己，性→身体主体性。
5. 不把女人变成病人。
6. 有明确女性视角。
7. 少说教，多用“我越来越觉得……”“也许我们可以……”。
8. 金句必须从前面的逻辑自然长出来，不硬煽情。

### H｜Health & Risk 专业与风险审校

红灯：无证据、明显越界、重大误导、疗效承诺、把个案当规律，必须删除或补正。

黄灯：有事实基础但口径太满，需降低确定性、补充边界或复审。

绿灯：事实、经验、推演和观点边界清楚，可发布。

重点排查三类错误：
- 把可能说成必然。
- 把相关说成因果。
- 把个案说成普遍规律。

## 7. 商业承接六问

每条内容生产前检查：

1. 吸引的是不是我要的女人？宁可精准，不追无关围观。
2. 看完以后，她会不会更相信澜心？
3. 有没有让她理解澜心的方法论，而不只是记住一个知识点？
4. 能否自然连接现有训练、课程、产品和线下服务？
5. 内容本身有没有完成一次“小交付”？
6. 即使用户不购买，她是否仍获得真实价值？答案必须是“有”。

当前可连接业务包括但不限于：元气女人气血营、盆底/核心训练、减脂塑形、营养支持、身体伴侣训练器、私域训练营、线下女性健康服务、高阶课程、疗愈生活馆。

## 10. 一周运行节奏

### 周一｜补料

收集评论、私信、学员问题、早课、澜心灵感、专业研究、热点、竞品和业务一线反馈。

### 周二｜选题会

AI先跑D生成30—50题，人工删除重复、空泛、越界、身份不匹配和缺材料的题，留下Top10；再跑E确定本周核心题。

### 周三｜生产

先写事实清单 + 结构，经确认后再出逐字稿。

### 周四｜澜心化

澜心本人重点修改1—3篇。团队必须记录“为什么改”：太像AI、太专业、没女性感受、太说教、不像澜心、观点不够深、金句硬、缺身体连接、商业味太重、医疗口径太满等。

修改理由进入表达规则库，作为后续训练样本。

### 周五｜数据对账

不仅看播放量，还要看：
- 流量：3秒/5秒停留、完播。
- 内容价值：点赞、评论、收藏、转发。
- 信任：主页访问、关注。
- 商业：私信、加微、直播间进入、报名、产品咨询、到店、成交。

### 周末｜复盘

回答五个问题：
1. 为什么她停下来？
2. 为什么她看完？
3. 哪句话引发最多评论？
4. 吸引来的到底是不是我要的女人？
5. 这条内容给选题标准新增了什么规则？

## 13. V1.0测试说明

本SOP为V1.0执行版，不自动升级为不可修改的永久规则。

下一阶段测试方式：以真实直播逐字稿、评论区问题和发布数据作为样本，跑第一轮“D找题 → E筛选 → I结构 → T澜心化 → H审校”，重点检验：

1. 五项权重是否符合真实数据。
2. 哪些用户原话最容易长出高质量选题。
3. 哪些题虽然得分高但不适合澜心表达。
4. 哪些低分题因澜心个人经验和表达反而表现突出。
5. 不同类型题对精准关注、私信、直播和成交的贡献差异。

只有经过真实内容数据验证后，再进入V1.1调整。
