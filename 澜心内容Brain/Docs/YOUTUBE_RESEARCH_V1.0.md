# YouTube 国际研究｜用国际材料提出更好的问题

**从一句话开始：**“研究 YouTube 上女性盆底和围绝经的视频，看看哪些值得我讲、哪些适合备课。”执行者从[总览与已有批次](../Content/研究资料/YouTube国际研究/README_YouTube国际优质内容研究总览.md)查重，读 Brain/03、04、05、07、09、[选题SOP](LANXIN_TOPIC_SOP_V1.0.md)和[报告标准2.2](RESEARCH_REPORT_STANDARD.md)，自动填写本轮目标、受众场景、优先主题、路线、计划与上限、可用环境和停止点。指定账号不是授权无限采集。只查最影响正确性的缺口，其他工作并行推进。

YouTube 帮助理解国际表达、专业知识与课程结构；[小红书](XIAOHONGSHU_TOPIC_RESEARCH_REFERENCE_V1.0.md)帮助观察中国受众处境。两者可支持同一问题，证据各自标注；海外流量不代表中国女性需求，中国评论也不证明专业观点。YouTube 不套用小红书的 B1/B2/B3、预算或统计。自己的素材仍可直接进入共创。

## 来源、发现与两条路线

- **来源角色 A 专业、B 表达、C 讨论**是用途，可多选但逐项给证据；与下述路线 A/B 无关。按频道 ID 与创作者矩阵去重；单个讲者以其具体主张的资质、机构、利益关系和外部证据核验，频道认证仅说明身份信号。个人体验、广告、机构科普、访谈嘉宾观点、指南分开。受众是频道可见定位或研究假设，无法得知实际人口构成时写未知。
- 同时从已核频道和主题词找视频；用专业术语＋用户生活语言组合，例如 pelvic floor relaxation / can't tell if I'm doing Kegels、perimenopause / what to tell my doctor、relationship repair / can I say no、interoception / noticing bodily signals。记录实际查询、入口、日期、排序、可见范围、重复与取舍；搜索和推荐流可能个性化，先收机构来源再加入反例。优先近期，允许仍有价值的旧作品并注明时效。
- **路线 A：≤10:00**，普通视频和 Shorts 分开。研究公开传播、内容解释、表达设计与评论；选题需要自己的中文问题、可靠依据和独立表达。
- **路线 B：>10:00**，优先 30–120 分钟的讲座、深访和课程；10–30 分钟可作专题。先核讲者、层次、主张、教学组织、现行指南和证据局限。用章节问题拆解，不能按时长机械切稿；低播放不是淘汰依据。
- 首轮计划参考 A 30–50、B 8–15，合计深读 8–12。后续手动任务按目标填写，未另定时以本轮参考上沿作工作量上限，不为凑数扩题；评论先观察每条热门与最新各一段连续可见窗口，各最多 10 条主评论，必要回复另记，单视频合计不超过 30 个可见条目。只作研究抽样设计，并非平台授权。达到本轮约定上限、同源重复无新增、风险不可控、权限不清或无法读正文时停止相应路径；部分完成照实交付。

## 先过五关，再评分

| 门槛 | 通过所需证据 |
|---|---|
| 1 来源可核查 | 频道、视频、日期、所用正文及相关语境可回查。元数据页不是已读内容 |
| 2 方向相关 | 指出具体受众场景或研发目标；纯形式材料限表达用途 |
| 3 可靠回答 | 关键事实有可追溯支持；医学/心理主张核资质、适用人群、原证据、现行指南及替代解释。非专业内容解释何处不适用 |
| 4 权利与制作 | 用自己的素材和结构能拍，明确权限，具备人员和审核条件 |
| 5 伦理与风险 | 不传伤害性主张、羞辱、未经同意的个人证据或疗效保证；拟发布另核账号与平台 |

每项写通过／待补证／不通过与理由。待补时只登记证据与下一步；不通过时排除该用途，合理保留纯形式对照。禁止用总分补偿门槛缺口。

| A 短视频 | 满分 | 给分依据 |
|---|---:|---|
| 受众及方向 | 25 | 场景、问题与 Brain 对应 |
| 可信度及解释 | 20 | 关键事实可追溯，解释完整且有边界 |
| 评论价值 | 20 | 有具体问题及语境；能区分反例、纠错与普通称赞 |

| **合计** | **100** | 80+ 优先，65–79 观察，低于 65 通常暂缓 |

| B 长课程 | 满分 | 给分依据 |
|---|---:|---|
| 讲者、证据及可信度 | 30 | 具体资质、主张可查、与指南证据相容 |
| 深度、结构与解释 | 30 | 问题、理论、解释、论据和边界读得到 |

每维用实际证据评分，0 只用于有证据显示没有该项价值；缺资料标“未评”，不加权折算、不报完整总分。三项结论（传播、知识、原创）分别写，A/B 总分不横比。评分是内部排序，不是医疗认证或成片预测。

## 网页、字幕、指标与评论

1. 先在可用浏览器打开官方频道、准确视频、简介及播放器；正常登录仅在需要时由本人完成敏感步骤，不索取或保存凭据。若浏览器或权限不可用，记录具体页面、步骤、现象和已尝试动作；可用发布者官网/同集正式文字补读，注明不是 YouTube 正文。官方 API 只是可选入口，须另有合规配置和访问权限；本框架不依赖 API 密钥或第三方下载器。遵守[服务条款](https://www.youtube.com/t/terms)、[API 开发政策](https://developers.google.com/youtube/terms/developer-policies)与访问限制；不用爬虫、隐藏接口或绕过流程。
2. 有字幕时从[官方逐字稿面板](https://support.google.com/youtube/answer/15930243)或获许可的同集稿件阅读。记录语种、轨道（作者提供／自动生成／未知）、实际区间、章节链接与说话人；有必要回听关键术语和否定句。原文短摘、中文译文、AI 概述和歧义单列。简介章节时间只标“导航”，未读正文时不作引文定位。资料不足时明确只读了什么，不凭标题补故事、论证或结尾。
3. 每次追加带时区的观察：原发布日期、时长、类型、播放/赞/评论数、其他真实可见指标，精确值与网页约数分开。未显示／未取得不等于 0；零仅在明确显示时记录。[公开字段](https://developers.google.com/youtube/data/reference/rest/v3/videos)的 favoriteCount 不作收藏量；Shorts 观看按当时口径，2025-03-31 起开始播放或重播可计入，无最低观看时长。CTR、观看时长、留存与来源依[获授权分析](https://support.google.com/youtube/answer/9002587)取得，不反推。
4. 优先同频道、同格式、相近时长及发布年龄，记录窗口与纳入规则，尽量至少 5 条；不足就报样本不足。相对播放 = 对象播放 ÷ 可比中位数；赞播比、评播比只用同一次观察且分母非零，约数计算明确约值。比较时披露样本、发布时间差、可见性、付费推广未知、重发/剪辑关系。标题、封面、内容结构是观察；解释是假设；没有 CTR、留存或实验不能证明因果。
5. 评论窗口记录排序、日期、范围、是否展开、主评/回复、作者身份显示、去重及排除。分类：具体问题、体验、赞同、质疑、纠错、作者补充、推广/疑似重复。昵称不用于确认独立人，评论只证明有人这样表达，不能估计患病率、需求比例或中国受众。敏感经历、未成年人隐私、可搜索的用户引文及定位不进 GitHub；没有获准受控证据位就不留原文或评论定位，公开只写去标识化主题并说明回查局限。

## 编号、复用与更新

- 批次 YTR-YYYYMMDD-NN；频道用平台频道 ID，视频用视频 ID；条目在批次内用 A01/B01；译段、评论窗口、证据与观察带批次和条目号，如 YTR-…/A01/O01、E01、W01。跨轮引用原条目，不按语言或 Shorts 链接重算；同一讲者、节目录像及切片相互指向。课程站点与 YouTube 同集要验证，异集作独立证据。
- 结果状态写发现／元数据可读／正文部分可读／已深读／待补证／排除及具体理由；与 Content status 分开。无实际评论时评论栏注明状态。正式报告按[中文模板](YOUTUBE_RESEARCH_TEMPLATES_V1.0.md)交总览、逐条报告、证据附录，另接拍摄理解页和口播。
- 权限和版本同一主记录：公开 GitHub 只存原创释义、非敏感链接和必要合法短摘；受控版可存获准内容及完整定位，编号和结论一致。翻译全文、下载或在课程中播放/复制必须另核许可、地区和具体用途；能播放或见到“不公开”链接均不自动授予再分发。记录授权主体、用途、存储和保留期限；权利不明只保存原创判断和非敏感索引。
- 课程先查[国际医学证据路径](INTERNATIONAL_MEDICAL_EVIDENCE_PATH_V1.0.md)与现有[内容/课程入口](../Content/README_内容共创流程.md)。教学问题与章节索引可先登记，主张仍走原研究或指南核验；不能靠讲座证明疗效。相同文献/教材只加关联。候选共创先查原 Content，避免同题重复建档；需新建时按[唯一视频系统](VIDEO_CONTENT_SYSTEM.md)编号。明确要求的试稿用 drafting，待确认、必要专业审核和具体平台条件。长期 Brain 只在澜心明确确认后修改。
- 建议有选题任务时补短视频、按研发需要补课程，定期复核来源和评分；快照和观察追加，纠错写原判断、日期、变更原因及影响，不覆写历史。发布后按既有 Reviews 追加真实数据复盘，调整方法有依据再修订版本。未建立自动任务。
- Chat 管目标、复核、共创；Work 或可用的 Codex 浏览器承担实际研究；Codex 管公开归档与版本。用[Work入口](../Prompts/09_Work执行入口.md)与下次实际读回；未发送、未配置、未独立执行分别标明。

## 1.1｜从已读材料到可录制的稿件

延续现有双路线和评分。短视频先完整核读作者的开头、论证、例子、转折及结尾，再列观众证据和原创判断。正文可来自可核验的同集官方稿件；公开转载文字须另标层级、与原作对应证据及影音缺口。发布者提供的历史传播数据注明原样本与日期，不能填成当期公开平台数据。长课把理论框架、研究样本、讲者解释和对现有课程的用处分开。一堂课可派生多个独立问题，每题先与现有档案去重。

要求完整阅读件时，先维护正式研究正文和单一 Content 主档。用同一批次与版本生成中文 Word，汇入拍摄理解和完整口播，目录与来源可点击。文档交付前实际渲染和检查。公开仓库保存可复核的生成依据与必要链接；受控阅读件按任务授权保存，实际上传、登录与跨端读回以各自回执为准。实例见[完整研究与执行报告 1.1](../Content/研究资料/YouTube国际研究/2026-11-13_完整研究与执行报告1.1.md)。
