# 系统地图

~~~mermaid
flowchart LR
  A["澜心碎片灵感 / 原话"] --> B["Inbox<br/>原话保护"]
  B --> C["内容共创<br/>讨论与澄清"]
~~~

## 模块职责

| 模块 | 负责什么 | 不负责什么 |
|---|---|---|
| Brain | 经确认的长期身份、价值、表达、方向与边界 | 原始聊天全文、一次性草稿 |
| Inbox | 完整接住原话和碎片 | 自动写全文、覆盖原话 |
| Content | 讨论、选题、结构、稿件、视频档案、逐字稿与确认记录 | 把研究中观点说成定论，保存原始媒体 |
| Reviews | 发布记录、追加式数据快照、真实复盘与下一次实验 | 覆盖历史数据，用单条数据下因果结论，保存后台原始截图 |
| Project资料同步包 | 给 ChatGPT Project 读取的紧凑快照 | 第二个事实库 |
| Docs | 状态、决策、系统与资产索引 | 承载所有业务正文 |
