## 1. 定位与使用边界

2026-10-21按本轮专项升级prompt与四份新附件原位升级V2.1，保留原文件路径以免既有链接失效。这里同时承担专项入口与后台标准；模板、来源差异及数据使用见[模板说明](XIAOHONGSHU_RESEARCH_TEMPLATES_V2.1.md)，测试与未验证项见[专项验收](XIAOHONGSHU_V2.1_ACCEPTANCE_2026-10-21.md)。

遇到小红书用户评论研究、外部找题或复核研究统计任务时读取本文件。Chat调度并复核，Work按授权执行并交回中文报告和候选共创摘要，Codex维护正式规则。附件中的“另一个账号B”只可作为可选Work环境，不另建Brain、动态事实主库或第二个选题库。个人灵感、直播、课程、经历和研究仍可直接进入同一个Content，不强制先看热门笔记。

六方向是候选研究范围，由最新任务或已确认计划决定本轮一个主主题及两类优先来源，不自动全开、不预定盆底优先。关键词搜索是主要发现入口，对标账号是辅助。主要出口为原创短视频，计划平台为抖音、小红书、微信视频号，具体账号与发布条件逐一核验。

本参考承接澜心于2026-10-16明确提出的运营任务：从小红书帖子及评论区寻找真实用户提出的需求与高互动话题，保留她们自己的语境，作为后续选题来源。六个持续关注方向为：两性健康、生殖健康、盆底健康、两性亲密关系、性教育、产后康复。

这六类是研究检索标签，不替代[既有四个内容支柱及比例](../Brain/04_内容方向_content_direction.md)，也不排除原有女性成长、生命体验等方向。生产仍走[澜心1.0选题SOP](LANXIN_TOPIC_SOP_V1.0.md)的D-E-I-T-H与风险审校。

核心纪律：用户原话、运营的需求判断、AI拟题分列；没有实际采集证据的句子，不称为“用户原话”；没有样本与统计范围，不称为“高频需求”。

## 4. 分批执行与唯一预算表

以下为Demo工作上限，不是平台官方阈值、采集配额或效果承诺。任一适用上限达到即停止对应动作；查询、观察、脱敏、分类、整理及报告都计入所属阶段，不叠加子任务时间。不足目标可交有限结论或零推荐，预算只能在新任务启动前由澜心明确调整；更改范围或下一批需要相应授权，已给出的具体授权不重复询问。

| 阶段 | 进入条件 | 目标与硬上限 | 结束与返回 |
|---|---|---|---|
| B1首次能力验证 | 指定测试对象、环境、范围和授权具备 | 1条指定笔记；最多5条可见且可安全脱敏评论；最多20分钟 | 入口、对象、内容、评论、连续观察、来源保存的真实记录与限制 |
| B1独立会话复验 | 首次记录可核；后续独立会话及获准对象 | 同条笔记及同范围另一条笔记；沿用小范围、总评论不超5条；总计最多20分钟 | 两次会话分别留环境、证据和人工介入记录，不复用截图冒充复验 |

### 受控采样记录字段

1. 样本编号、采集日期、搜索词与所用排序/筛选方式。
2. 来源账号及主页、帖子链接、发帖日期、评论定位与上下文。
3. 用户逐字原话：不润色、不拼接不同人的话；必要删节标明删节。
4. 稳定观察OID、归并CID及去重说明；不建个人身份档案，不额外搜集身份信息。
5. 采集当时帖子与评论的点赞、回复等可见数据，注明时间；不可见写“不可见”。
6. 用户场景与问题、运营的需求判断、AI拟题分别记录。
7. 同类表达来自多少笔记、多少去重后的可定位表达；独立用户数未知就不推算，昵称不同不证明不同真人。
8. 反例或不同意见、缺失信息、可能的广告/引流/复制评论。
9. 专业证据待核项、隐私与授权状态、可否进入公开内容。

一条可靠表达也可形成探索线索，多笔记出现仍须说明集中度、排序和自选择偏差，不能自动宣称“全站高频”。原3人/2帖只是旧试跑参考，不是合格硬门槛。点赞和回复不是患病人数；一个热门帖、重复展示、复制评论不能算独立需求。不得为去重追踪用户身份。

### 提交选题时最少带什么

按真实证据交付候选，数量不足或为0均如实说明。每个包括：
- 用户原话及可追溯证据（存于受控位置）
- 她遇到的具体场景
- 运营理解的需求（明确这是判断）
- 澜心可以回应的角度
- 需要补充的专业依据与安全边界
- 建议形式及与既有内容支柱的关联

未采集到原话时保持“待采样”，不得用本页搜索示例填充证据栏。澜心的优势是身体、情绪与关系的连接，不与医生比诊断、用药或治疗承诺。

## 5. 隐私、公开仓库与发布边界

本仓库为公开仓库，仅保存方法、检索词、空白模板、公开安全的去标识化洞察及必要书目索引。真实评论、截图、健康与性生活自述、用户标识、可反查个人的评论定位及受控资料链接不进入这里；仅去掉昵称并不必然完成匿名化。

原始证据放在经授权的受控采样记录中。公开使用另做隐私和授权检查，不搬运完整帖子、原图或可识别的评论截图；不要将陌生人的自述包装成澜心学员案例。用户自述只能证明“有人这样表达”，不能证明医学事实或因果关系。

平台规范应在具体采集或发布前复核：[小红书相关公约入口](https://pgy.xiaohongshu.com/help/detail?id=1eda0a065dd894063c2e029a49e8f6a1&userType=4)。账号流量和平台可见性不等于医学可信度。

## 6. 接入后续内容工作

每轮先回到本参考确定采样方向，再使用既有选题SOP筛选；保留“真实原话 → 需求判断 → 候选选题 → 事实核验 → 澜心确认”的区别。已有[20个用户提问型选题](../Content/选题库/女性身体健康_用户提问型选题.md)继续作为待研究验证的旧资产，不因本次同步自动成为已验证高频需求。

本次确认的是后续找题方向和真实用户语境优先的工作要求；账号适配性、具体关键词表现、采样规模和内容效果仍须实测。未创建自动采集或自动发布任务。

## 7. 能力验证与连续观察

正式平台研究前核实际交互浏览工具、必要登录、资料读取、权限和证据保存位置。搜索摘要或静态网页读取不证明能打开评论区。首次验证使用一个获授权的笔记或账号对象，只观察1条笔记、最多5条可见且可安全处理的评论：验证入口、登录、对象匹配、图文/视频已读范围、评论显示、至少两次连续观察与排序变化、来源证据关联。记录耗时、人工介入、失败环节和未验证项。

再于独立会话复验对象识别、登录延续、连续观察和证据定位，记录环境差异；对象数量、时间和范围严格执行第4节。两次成功只证明对应范围的能力，不证明长期稳定、全量评论可见或授权扩大。正式小样的主题、范围和资源由当前授权决定，已确认的不反复询问；没有测试对象时只问最关键的一个条件，AI自动生成执行说明。

登录、验证码由用户正规操作，不索要凭据，不绕过访问限制，不调用未授权接口。遇明确风控停止相关路径；一般页面异常仅在原范围内有限重试并记结果。未发生实际访问时写未测试，不假设失败。

每条深入笔记先记录排序、折叠与已见范围，连续观察有首尾标识的窗口；切换排序、展开回复或滚动发生断层时另记批次，不能拼成虚假连续样本。保留反例、不同观点和排除计数；广告、纯互动、隐私风险分别说明。未显示互动写未显示，截断内容不补全。无评论直链时以笔记、观察时间、位置、回复结构和受控证据定位；仍无法复核就待补证，不计合格数。

技术重复只计一次；同文复制、疑似模板、同义不同来源分别标记，不能仅凭措辞相似认定同一人。真实表达只证明当时可见，不证明身份、经历或医学事实。样本范围到达、重复明显增加、隐私处理负担过高或平台限制均可停止并说明影响。

## 8. 五项硬门槛与研究层级

| 门槛 | 必要依据 | 未满足时 |
|---|---|---|
| 来源可核查 | 原始表达、上下文、时间与定位对应 | 待补证 |
| 与受众和内容方向相关 | 已确认Brain人群、方向及本轮目标 | 缩小或排除 |
| 澜心能可靠回应 | 真实知识/经验、可靠专业来源、必要资格和审核责任 | 留待补证，不虚构能力 |
| 能形成原创且可制作的角度 | 单一核心问题、观看价值、形式理由、必要人员素材及授权 | 条件不足则暂缓 |
| 专业伦理与合规边界可守 | 内容类别、来源、隐私版权、专业边界、逐平台预审 | 回退或停止 |

逐项用通过／待补证／不通过，不能用总分抵消关键风险。旧SOP评分仅在硬门槛通过后帮助比较，不是需求规模或传播预测。主目标没有指定时不默认咨询或成交。

研究证据层级为S1真实表达、S2有效问题、S3潜在机会、S4适合澜心方向、S5可制作核心选题、S6人工研究审核。S4需可靠回答能力；S5需五门槛在研究推荐范围内通过和必要人员素材落实；S6需对具体版本的业务及必要专业审核。证据变更可回退并保留依据。任一门槛待补证不得升S5；不通过则排除或重定角度。

S1—S6不写入Content status，也不与Brain原话来源中的说话人确认等级S3混用；应写“研究层级S3”或“原话确认等级S3”。个人素材路径引用实际素材，不必先造一条用户评论来满足S1。S6不等于内容approved、开拍授权、平台许可或真实效果。

## 9. 三平台与四个审核节点

研究选题时分别写抖音、小红书、微信视频号的初评，依据、账号条件和官方规则缺口均可见。使用[报告标准](RESEARCH_REPORT_STANDARD.md)的五种初评状态；未知不能判不适合，不要求三平台全部通过，但影响核心回答安全的缺口不能借拆分绕开。

依次保留四个审核节点：检索与候选来源/隐私；具体专业事实/适用人群/真实审核责任；文案及标题封面/引用/隐含承诺；各平台正式发布版本/账号认证/广告与素材权利/AI标识/授权。每个节点只在该任务实际进入时核验，不审不存在的成片。

本轮继承V2的风险管理方法，不把其2026-10-18“已读”的法律、医学或平台条款冒称本轮已重新核验。视频号规则缺口仍待实际取得；抖音、小红书也必须按具体任务复核现行官方正文及账号适用性。既有专业研究路径和书目索引用于寻找直接来源，不替代逐项核验。

本项目禁止个体诊断、无依据治疗/训练处方、疗效承诺、虚构研究与案例、身体羞耻、低俗擦边、强迫叙事、未成年人私密经历收集、隐私暴露、未授权搬运及变相规避审核。风险记录写触发点、依据、影响范围、待核项、责任人与解除条件；不把管理风险等级说成平台官方处罚等级。

## 10. 失败、复审与返回

访问阻断：停受阻动作，记录实际现象和环境，用户合法处理后再验。证据不足：缩小结论或补定位，不能推导不存在需求。价值/能力/合规不符：排除或暂缓相应题目，说明能否补齐。不得用换平台、换账号或变体词隐藏原风险。

用户提供脱敏材料可作为替代来源，在已有授权范围内分析，注明用户提供且未自行浏览；改变采样范围时说明并取得缺失授权。返回结论、完整逻辑、证据索引、失败及待办，按[一句话执行规范](ONE_SENTENCE_EXECUTION.md)交接。没有真实反馈不得宣称澜心已经理解或认可报告。

## 11. 从一句话建立一轮研究

Work自动从本次任务和Brain读取：一个主主题、两类优先来源、目标女性人群与场景、一个主要内容目标、允许访问的对象和范围、真实回答能力及专业审核责任、时间与数量预算、实际浏览器与必要登录授权。目标缺失不默认销售；40岁切面不改变Brain的30+总人群，更不能推定评论者年龄。

主主题不明时先展示相关矩阵建议，不能默认盆底或展开30组合。两类来源和预算若已在当前授权中明确采用即沿用；只有建议而未确定时，先整理可行选项与关键词，阻断正式浏览，只问当前最关键的一项。不要发11项技术任务书。没有浏览器也可准备设计和资料检查，输出状态为待输入或待验证，不能编造评论或访问失败。

一本工作簿对应一个RUN。AI在获准受控位置复制空白模板，建立RUN、规则版本、批次BID和“研究／能力验证”范围。稳定编号为RUN、K关键词、Q精确检索、A账号、N笔记、O观察、C规范评论、P问题、L关联、T选题、E证据；行号不能作永久编号，跨表与跨批均按ID关联。指标L须写全“可定位去重评论数（L）”，区别关联LID。

P0=研究、问题发现、原创视频核心选题与风险预审和人审；P1=另获任务后的文案与制作、具体平台适配；P2=另获授权后的发布及反馈。它们不作主题优先级、研究证据等级或Content状态，也不与视频SOP剪辑优先级P0—P3混用。研究不自动写完整脚本；澜心明确要求写作时可以直接利用已确认研究资料，不重新启动研究。

## 12. 搜索路线和停止条件

从04矩阵中提出专业词、生活词、场景词各一个，并说明与本轮人群和目标的关系。完整六主题×五来源=30种路线，不是30个待执行任务；来源优先级是方法建议。矩阵里称为截图原词的内容本轮只核到附件转述，IMG1/IMG2尚未核原图；衍生组合与原词分列，均不作医学证据或已验证需求。

| 动作 | 试运行上限 | 实际必须记录 |
|---|---|---|
| A关键词→笔记→评论→发现账号 | 全轮A+B合计最多6次精确检索；三起始词之外最多3次同主题扩词或替换 | 精确词、理由、实际排序及过滤、开始结束时间、首尾显示序号、选入/排除原因 |
| 每次检索 | 前10个实际显示结果或10分钟，先到者止 | 页面未返回、排序不可见、未读正文等如实写，不假设“最热”按钮或全站榜 |
| B账号类型→候选账号→笔记→评论 | 最多2次账号类型检索，包含在总6次内 | 触发原因与所补缺口，不能重置检索或连续失败计数 |
| 账号池与补看 | 最多6个候选；每账号最多3条最近可见笔记或10分钟，先到者止 | 实际日期、阅读范围、六项筛选证据与不足，不追踪评论者主页 |

只有前三个起始词均无相关安全笔记，或前两篇深入笔记明显同质/同来源时，才考虑B；A仍优先，不因想增加推荐数开B。换词先有无相关结果、营销同质或语境不符的记录。两次连续合法换词仍无可定位信号，或两条深入笔记均无有效问题，停止探索小样并返回，不升B3。至少尝试低互动、反方或不同场景材料；不能覆盖时写限制，不能放宽隐私或来源要求。

账号逐项检查：主题相关性、人群与场景、内容持续性、评论问题信号、专业及商业倾向、可访问与可取证。初步通过的试行标准是：最多3条可见笔记中至少2条同主题、至少1个明确目标场景、至少1个安全可定位实质评论问题、页面和来源可核且无阻止研究的风险。不足标待补证，不证明不适合；粉丝数、自称头衔或认证图标不证明可靠回答能力。

“发现候选”“初步通过”“实际用于研究”分开。A可使用通过笔记闸门的单条材料并注明账号持续性未核；B须先初筛账号。实际使用不反推初步通过，更不证明专业资质。补充第三类来源或跨主题需回Chat取得范围调整授权。

## 13. 九项统计和解释边界

| 指标 | 本轮正式研究口径 |
|---|---|
| O 实际观察条目 | 非空且唯一OID的实际显示观察次数，包含重复、无效与隐私排除；重复观察建立新OID，同一OID误抄须纠错，不能算新观察 |
| D 已判定去重评论 | 已判定的不同CID，包含安全可判重的无效、广告、纯互动；不能先筛有效再算分母 |
| U 未完成去重判断的观察 | CID缺失或归并待核的O；无法安全归并的隐私排除也单列，不静默删除 |
| L 可定位去重评论 | D中有可复核来源且隐私安全的不同CID；后续补定位只补计一次，D可大于L |
| V 有效问题评论 | 至少支持一个有效问题，且来源与隐私合格的不同研究CID；一条支持多问题只计一次 |
| G 有效问题类别 | 至少有一个有效支持关联的有效PID；同义同场景合并，不按标签数累计 |
| 候选选题 | 不同TID，含探索、暂缓、排除 |
| 正式推荐 | H1—H5逐项通过、S5/S6、可靠支持、完整理由及三平台初评齐全、人工标推荐的不同TID |
| 澜心明确认可 | 对具体版本有明确认可依据的正式推荐；AI评分或人工尚未审核均不自动认可 |

V/D仅描述本轮已判定去重子样本的问题信号比例，不是女性用户占比、疾病发生率、总体需求规模或商业转化率。D=0显示“不适用”；未执行显示“未执行”；执行后尚无认可可为0。必须披露U及原因，不能声称全部观察已去重。原始公式与修正记录见模板说明，填充后必须检查编号、关联、数据验证与容量，再按真实材料复核。

问题—评论关联一行一个P—C关系，分支持、反例、背景和待判；重复关联不重复计支持，同C可支持不同P。问题支持数是不同CID；支持笔记数是可定位规范来源的不同NID，均不等于独立用户人数。跨笔记同文须人工判重；若归同CID保留重复证据和规范来源，不用拷贝传播伪造多源支持。语义相近不等于同一表达或同一人。

分类先读上下文，区分提问、经历、转述、讽刺与作者回复。合并、拆分、CID纠正和支持关系修订保留理由及受影响编号，重算指标；源记录不覆盖成AI观点。

## 14. 研究后台状态与能力四分记录

研究后台状态只存RUN/批次，不写Content status：待输入、待验证、正在研究、证据不足、候选待审核、研究完成、受阻停止。

补齐关键输入后待验证；B1必需链路及独立复验通过、获B2授权且实际开始后才可正在研究。来源、判重或问题不足进入证据不足；形成候选而人审未完成进入候选待审核。权限、隐私、范围或预算阻断记受阻停止，附时间、对象、已尝试动作和解除条件。恢复需合法解决阻碍并核剩余预算，不复活已耗尽额度。

“研究完成”需Chat复核并记录本轮约定范围已满足。约定止于候选人审而人审未完成时不能完成；如Chat接受限定范围交付，要写未结事项及责任，不能冒称澜心认可。报告分别记录：①规则已建立及版本；②工具已配置的实际证据；③访问能力验证的环境/日期/范围；④真实研究的RUN/结果/限制。文档或公式测试只证明①的相应检查，不能推导②③④。

## 15. Work交回Chat的共创包

必须同时交：中文三层研究报告、筛选后的原创视频候选、逐题完整推荐理由、已确认事实与待核项、可继续共创的摘要。不能只交Excel。按[报告模板的共创卡](RESEARCH_REPORT_STANDARD.md)交每题的工作标题、具体场景、核心问题、评论与研究证据、IP联系、可靠独特解释、一个候选核心观点、内容价值、原创形式、专业边界、制作条件及推荐/暂缓原因。

工作簿及必要证据留获准受控位置；交Chat只用获准必要内容，给Codex只用公开安全索引。研究TID映射已有Content时先查重，没有正式Content ID就标未入库；不自动创建Publish记录。评论不变成澜心原话，AI候选观点不自动进入Brain，原账号结构和素材不搬运成“原创”。
