# 小红书对标账号与真实用户选题执行参考

## 1. 定位与使用边界

本参考承接澜心于2026-10-16明确提出的运营任务：从小红书帖子及评论区寻找真实用户提出的需求与高互动话题，保留她们自己的语境，作为后续选题来源。六个持续关注方向为：两性健康、生殖健康、盆底健康、两性亲密关系、性教育、产后康复。

这六类是研究检索标签，不替代[既有四个内容支柱及比例](../Brain/04_内容方向_content_direction.md)，也不排除原有女性成长、生命体验等方向。生产仍走[澜心1.0选题SOP](LANXIN_TOPIC_SOP_V1.0.md)的D-E-I-T-H与风险审校。

核心纪律：用户原话、运营的需求判断、AI拟题分列；没有实际采集证据的句子，不称为“用户原话”；没有样本与统计范围，不称为“高频需求”。

## 4. 采样起步建议与证据记录

可先每类选2个账号，共10个账号；六主题各看4篇，共24篇，作为可调整的第一轮工作量。此为内部试跑建议，不是用户强制固定标准，也不是代表性抽样或统计结论。

### 受控采样记录字段

1. 样本编号、采集日期、搜索词与所用排序/筛选方式。
2. 来源账号及主页、帖子链接、发帖日期、评论定位与上下文。
3. 用户逐字原话：不润色、不拼接不同人的话；必要删节标明删节。
4. 匿名用户编号及去重说明；不额外搜集身份信息。
5. 采集当时帖子与评论的点赞、回复等可见数据，注明时间；不可见写“不可见”。
6. 用户场景与问题、运营的需求判断、AI拟题分别记录。
7. 同类表达来自多少独立帖子、多少不同用户；计数口径与时间范围。
8. 反例或不同意见、缺失信息、可能的广告/引流/复制评论。
9. 专业证据待核项、隐私与授权状态、可否进入公开内容。

同一问题在3名不同用户、2篇独立帖子中出现，可以标记“值得进一步验证”，不能自动宣称“全站高频”。点赞和回复不是患病人数；一个热门帖、同一用户多次留言、博主自问自答或重复转发不能算独立需求。

### 提交选题时最少带什么

先交5个有真实来源的候选，每个包括：
- 用户原话及可追溯证据（存于受控位置）
- 她遇到的具体场景
- 运营理解的需求（明确这是判断）
- 澜心可以回应的角度
- 需要补充的专业依据与安全边界
- 建议形式及与既有内容支柱的关联

未采集到原话时保持“待采样”，不得用本页搜索示例填充证据栏。澜心的优势是身体、情绪与关系的连接，不与医生比诊断、用药或治疗承诺。

## 5. 隐私、公开仓库与发布边界

本仓库为公开仓库，仅保存方法、检索词、空白模板、公开安全的去标识化洞察及必要书目索引。真实评论、截图、健康与性生活自述、用户标识、可反查个人的评论定位及受控资料链接不进入这里；仅去掉昵称并不必然完成匿名化。

原始证据放在经授权的受控采样记录中。公开使用另做隐私和授权检查，不搬运完整帖子、原图或可识别的评论截图；不要将陌生人的自述包装成澜心学员案例。用户自述只能证明“有人这样表达”，不能证明医学事实或因果关系。

平台规范应在具体采集或发布前复核：[小红书相关公约入口](https://pgy.xiaohongshu.com/help/detail?id=1eda0a065dd894063c2e029a49e8f6a1&userType=4)。账号流量和平台可见性不等于医学可信度。

## 6. 接入后续内容工作

每轮先回到本参考确定采样方向，再使用既有选题SOP筛选；保留“真实原话 → 需求判断 → 候选选题 → 事实核验 → 澜心确认”的区别。已有[20个用户提问型选题](../Content/选题库/女性身体健康_用户提问型选题.md)继续作为待研究验证的旧资产，不因本次同步自动成为已验证高频需求。

本次确认的是后续找题方向和真实用户语境优先的工作要求；账号适配性、具体关键词表现、采样规模和内容效果仍须实测。未创建自动采集或自动发布任务。
