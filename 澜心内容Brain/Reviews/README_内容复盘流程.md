# Reviews｜把反馈变成下一次更好的判断

复盘不以单一播放量判断内容好坏，也不把一次结果升级为长期规律。

## 每条已发布内容的最小记录

~~~markdown
---
title:
published_at:
status: reviewed
content_card:
---

# 可见数据
- 播放/互动/主页访问/私信或咨询：如实记录，未知留空。

# 澜心感受
- 哪一处像自己？哪一处不像？

# 用户反馈
- 仅记录已去标识化、可引用的信息；区分个体反馈与普遍结论。

# 当前解释
- 已知事实：
- 可能假设：

# 下次只修改的一个主要变量

# 是否建议更新 Brain
- 仅提出建议；需要澜心明确确认。
~~~

## 视频发布记录的接入

已发布视频按一次发布一条 Publish Record 管理；每次补充后台数据均新增 Data Snapshot，不能覆盖旧值。平台原始数据、AI 计算指标、澜心感受、去标识化反馈与当前解释必须分开记录。

具体模板与规则见 [视频发布记录](视频发布记录/README_发布与数据记录规则.md) 和 [视频内容档案系统](../Docs/VIDEO_CONTENT_SYSTEM.md)。
