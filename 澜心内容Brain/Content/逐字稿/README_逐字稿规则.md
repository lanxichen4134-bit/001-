# 逐字稿规则

每条正式视频建立一个逐字稿，第一条真实记录时才建立年份目录，例如：

~~~text
Content/逐字稿/2026/C20260824-001_transcript.md
~~~

逐字稿必须保留三层，不能只保存经 AI 润色后的文本：

1. A. 原始机器转写：最大程度保留实际口语、重复与停顿。听不清写 [听不清]，不确定写 [待核]；人名、机构名、数字无法确认时不得脑补。只有可取得真实时间码时才写时间码。
2. B. AI 核对版逐字稿：可修正明显识别错误、补标点、分段、确认同音字、去技术噪声；不可改变原意、增添观点或改成漂亮文案。ai_checked_against_video 和 human_confirmed 如实填写；未获澜心确认不能称为确认版。
3. C. AI 整理版｜非原始逐字稿：可去重复、压缩、二创、提炼短视频版本或剪辑点，但必须明确说明其不属于澜心逐字原话。

从逐字稿提取金句时，视频实际说过的内容标为原话候选并附真实时间码（如有）；AI 改写则标为 AI 建议表达。二者都不得自动进入 Brain。

使用 [_TEMPLATE_逐字稿.md](_TEMPLATE_逐字稿.md) 创建真实逐字稿。
