# 盆底训练研究资料包

## 目录用途

这里是澜心盆底训练主题的研究资料入口，用于短视频、直播和课程研发前的证据核对。它服务于一般健康教育与内容研发，不构成个体训练处方、诊断或医疗建议。

## 唯一主正文

- [国际盆底肌训练循证书目与论文索引](./2026-09-04_国际盆底肌训练循证书目与论文索引.md)：国际指南、术语共识、系统综述、关键随机对照试验、专业书籍与患者资源的人工可读书目入口。
- [来源登记](./来源登记.yml)：供后续核验、权限审查和工具调用的结构化元数据。

本目录不保存来源专属的摘要、翻译、研究结果摘编或课程结论；需要使用具体证据时，应回到官方入口逐条核验其当前版本、版权状态与适用人群。

## 公开仓库存放规则

- 可以保存：自建书目信息、DOI/ISBN、出版社/国际学会/期刊的合法入口、许可状态与核验日期。
- `citation_only` 来源只保留中性书目和官方链接；不保存其摘要、译文、结论、图表、截图或其他衍生材料。
- `cc_by_reusable` 来源也默认只链接；如确有必要引用或改编，必须在对应条目中写明作者、来源、许可证链接和改动说明，并先核验第三方素材与再分发范围。
- 不保存：受版权保护的论文 PDF、扫描书页、付费内容下载链接、书籍全文、病历、测评原始资料或本机绝对路径。

## 调用顺序

1. 先按用户主题、症状与生命周期定位需要核验的来源，再回到官方入口阅读原始材料。
2. 涉及训练、症状判断或转介的具体表述，先进行专业复核；不从本目录直接生成个体化建议。
3. 具体内容卡只登记使用的来源 ID、核验日期和自建的公开安全审校结果，不复制证据正文。

## 维护

- 每 12 个月复核 EAU、NICE、WHO、Cochrane 与相关国际学会的更新。
- 新增资料前核对来源、适用人群、研究类型、结论限制与版权状态；无法核验的资料不进入主证据库。
