# Content｜先讨论，再成稿

每一条内容以内容卡为单位，而不是直接从灵感跳到完整逐字稿。

## 内容卡最小字段

~~~markdown
---
title:
status: discussing
content_pillar:
source_links: []
risk_level: low / medium / high
---

# 一个核心观点

## 为什么值得讲
## 用户具体处境
## 澜心真实体验或已授权案例
## 可用论据与证据层级
## 三个不同开头
## 内容骨架
## 表达/拍摄提示
## 商业承接（如有）
## 风险与待补事实
## 澜心确认记录
~~~

## 默认流程

灵感 → 讨论澄清 → 观点成立 → 三个开头 → 骨架 → 澜心确认 → 成稿 → 发布 → 复盘。

除非澜心明确要求直接成稿，否则不默认跳过讨论。个人故事、学员案例、医学表达和传统文化解释均需标出来源、授权/隐私与证据边界。
