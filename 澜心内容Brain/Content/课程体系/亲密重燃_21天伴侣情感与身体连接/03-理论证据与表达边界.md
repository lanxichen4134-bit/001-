# 理论、证据强弱与课程边界

## 如何读本报告的证据判断

以下“较有支持／有限／理论／暂无直接证据”是本轮研发判断，不是正式GRADE评分。研究设计、偏倚、对照条件、样本与课程的相似度都影响结论。指南的推荐强度、伦理重要性和某个课程的疗效证据不是同一件事。每项来源的核验程度见[12来源登记](12-来源登记与检索记录.md)。

| 主张或方法 | 现有依据 | 本轮判断 | 能用于本课什么 | 不能推导什么 |
|---|---|---|---|---|

## 关键理论如何转成教学

**生物、心理、关系与情境一起看。** 先问是否自愿、是否疼痛、是否疲惫以及现实分工是否可调整，再决定是否练习。注意力并不能消除疾病或不公平。本课不评估激素、不提供药物建议、不要求停用既有治疗。[E03、E09]

**回应性欲望不是“先答应再说”。** 有人先有兴趣再靠近，有人愿意尝试某种安全互动后才产生兴趣，也有人始终不想继续。开始的前提必须是对当下具体活动的自由同意；没有热情、没有身体反应或中途停止都不欠对方补偿。生理唤起不能作为意愿的证据。[E01、E02、E11]

**感官聚焦与本课的关系。** E03讨论的方法把注意力从“我表现得好不好”转向感觉，并指出直接研究与多样人群覆盖的限制。本课只借鉴这一原则，使用自创的手部、前臂及衣物外肩部练习；它没有复制完整治疗阶段，也没有进入临床渐进接触、性痛或性功能障碍治疗。为避免冒充治疗，学员材料称“低压力感官觉察／触碰练习”。

**图式是一个解释框架，不是身世判决。** 在L03只讨论现在发生的事、自己作出的解释和可提出的请求。可以问“我把沉默理解成什么”，不能追问“是谁在童年伤害你才让你这样”。同一反应也可能是对现实忽视的合理回应。无需找出童年原因即可练习更清楚的表达。[E07]

**放松不是义务。** 觉察练习可能无效、不舒服或唤起不良记忆。提供睁眼观察物件、移动、结束或跳过，不要求继续闭眼、同步呼吸、深呼吸或忍住反应。课程不把哭泣、颤抖、无感、僵住解释为“排毒、创伤释放或能量打开”。

## 对证据的主动限制

正念研究多为有特定困扰的女性及专业支持环境，关系教育研究与本课程的文化、招募和剂量不同；简短教育练习的效果不可直接继承。E04的两组都存在改善，不能把组内变化误说成独有机制。E13的在线临床项目与通用课程不同；E14是相关试验的机制分析，不作为第二个独立疗效试验重复计数。

本次没有检出本课程在中文成年伴侣中的直接试验，不等于证明无效。当前合理位置是“有理论与间接研究依据的教育方案，需先做可行性与安全试点”。任何未来“有效率”必须先定义结局、分母、缺失、对照和时间点。

## 可用与不可用的表述

| 可以说 | 不能说 |
|---|---|
| 学习表达需要、边界和偏好 | 让伴侣离不开你／挽救婚姻 |
| 有些人会在安全、愿意的互动中出现兴趣 | 女人先配合，欲望自然会来 |
| 这是一项可选的身体觉察练习 | 唤醒沉睡神经、打通能量、修复创伤 |
| 某些临床方案有研究支持，本课尚待验证 | 国外临床证明本课程21天有效 |
| 两人共同调整时间和负担 | 女人变性感，男人就会更爱你 |
| 疼痛时停止并寻求评估 | 忍一忍就开了／这是释放反应 |
| 亲密可包含陪伴、倾听、触碰与自主选择 | 性生活次数越多就越健康 |

## 待验证与推翻条件

若真实学员更需要医疗或创伤支持，缩小招生与身体练习范围；若触碰增加催促和报复，暂停对应单元；若双方报告差异扩大，不用平均分掩盖；若非接触版本同样可用且负担更低，优先保留简化版；若新的高质量研究否定特定机制，更新讲解与来源，不以品牌经验覆盖证据。
