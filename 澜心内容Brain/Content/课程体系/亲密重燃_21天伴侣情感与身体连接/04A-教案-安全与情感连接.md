# 第一阶段：安全与情感连接（D1—D7）

U1安全和共同目标含L01—L02；U2需要与回应含L03—L04。每课50分钟，所有案例为AI原创虚构情景，不是学员故事。讲师先读[09规范](09-讲师规范与安全转介.md)，学员先获[06手册](06-学员手册.md)。课堂练习均为纸卡、个人书写或自愿角色演练，不安排触碰；可旁听、跳过或离开。

## L01｜亲密的第一项能力：可以选择，也可以说不

- **日程与目标**：D1，U1。学员能说清具体活动的同意、撤回和无惩罚拒绝；完成一份自己的参与选择。
- **材料**：手册、K01同意卡、知识题Q1—Q3；提供不开摄像头/纸笔版本。
- **研究锚点**：E01、E10为伦理与安全依据，不代表本课效果已验证。

| 分钟 | 教学动作与讲师提示 |
|---|---|
| 0—5 | 说明成人教育、隐私和退出渠道：“今天不需要分享性生活，也不需要证明你愿意亲近。” |
| 5—15 | 区分关系身份、同意、身体反应。示例：已婚、曾经同意或身体有反应，都不代表此刻同意；沉默不能当答应。 |
| 15—25 | 虚构案例：甲说今天只想聊天，乙说“都报名了为什么不试”。让学员找出压力来自何处，重写为允许拒绝的邀请。 |
| 25—45 | 个人填写K01；自愿两人以“是否一起散步”演练邀请—选择—回应—撤回。旁听者用纸卡判断，不扮演真实伴侣冲突。 |
| 45—50 | 退出条：写一句拒绝和一句尊重拒绝的回应；讲师只点评行为，不评价人格。 |

**关键话术**：“谢谢你告诉我。今天就不做，不需要补偿。”“愿意听课，不等于同意任何身体练习。”

**误区纠正**：把“试一下就好”说很多遍仍可能形成压力；完成率不能高于选择权。付费不产生接触义务。

**检查与课后**：能在无解释、无承诺以后补做的情况下说停并停止追问，才完成技能演练；未做到回到纸卡练习。D1只设个人目标与基线，不安排触碰。任何害怕拒绝后被报复的情况转私下安全支持，不要求当众陈述。

## L02｜从“谁不够爱”转向看见疏离循环

- **日程与目标**：D2，U1。能分开事实、推测、行为和后果，找到一个双方可选择的小改变。
- **材料**：K02循环卡、三个虚构生活场景；不收集真实争吵记录。
- **研究锚点**：E05、E06为间接关系研究；循环图是本课原创教学工具。

| 分钟 | 教学动作与讲师提示 |
|---|---|
| 0—5 | 复查退出和保密；本课不分析谁“有问题”。 |
| 5—15 | 讲解事件→解释→行为→对方反应；说明压力、睡眠、照护、健康和真实忽视可能共同作用。 |
| 15—25 | 案例：下班后甲追问，乙看手机沉默，甲提高声音。先画可观察行为，再列至少两种解释，不把性别当原因。 |
| 25—45 | 个人用虚构情景画K02；可自愿与同伴比较。每人选一个自己能做的行动和一个可提出但不能强迫的请求。 |
| 45—50 | 复盘：“哪一项是事实？哪一项待核？哪个行动能由你决定？” |

**关键话术**：“我观察到我们十分钟没说话，我猜自己被忽视了；这个猜测还需要确认。”

**反例与边界**：如果实际存在威胁、强迫或经济控制，不能画成双方对称的沟通循环。停止修复任务，按09文件分流；受害者不承担修复施害行为的责任。

**检查与课后**：出口作业须有一条事实、两种可能解释、一项可撤回请求；D2两人各说一项希望恢复的连接，也可只写个人版。D3练习倾听，暂不讨论最激烈争议。

## L03｜我真正需要什么：事件、解释与自我图式

- **日程与目标**：D4，U2。能识别自动解释，表达一项当前需要；知道图式既非诊断也非童年命运。
- **材料**：K03事件—需要卡，空白纸；不使用童年创伤问卷、不收父母或伴侣评价档案。
- **研究锚点**：E07为关联证据，不能支持本课改变图式或治疗创伤。

| 分钟 | 教学动作与讲师提示 |
|---|---|
| 0—5 | 明确无需回忆童年；可以全程用虚构人物。 |
| 5—15 | 解释“图式”可理解为反复理解自己的习惯框架。提醒实际不公平、疲劳、当前关系行为也会影响感受。 |
| 15—25 | 案例：伴侣忘记约定，甲想到“我不值得被重视”。分别写事实、解释、感受、需要；替代解释不能用来否认失约。 |
| 25—45 | 完成K03并改成请求：“我希望计划改变时提前告诉我，你愿意试一周吗？”同伴只判断请求是否具体、可拒绝，不分析对方童年。 |
| 45—50 | 每人自查：有没有把推测当事实？有没有替伴侣读心？ |

**关键话术**：“过去可能影响我们，但不需要证明过去发生了什么，才能表达现在的需要。”

**误区与停止**：不把羞耻、愤怒或不想接触解释成缺陷；不引导回溯、催眠、记忆重建、父母和解或宣泄。出现惊恐、僵住或难以回到当下时停止个人探索，提供睁眼、离开及专业支持选择，不做当场解释。

**检查与课后**：用虚构案例清楚区分四项即可完成，不以私人披露深度评分。D4完成卡，D5改写为一个当下可执行请求。

## L04｜让回应变得可信：倾听、邀请与暂停

- **日程与目标**：D6，U2。能复述对方需要，作真实可履行的回应；能提出暂停与约定回谈，不把暂停用作惩罚。
- **材料**：K04倾听卡、K10修复卡、计时器；选择低冲突话题。
- **研究锚点**：E05—E06是方法方向参考；三分钟轮流表达为原创教学剂量。

| 分钟 | 教学动作与讲师提示 |
|---|---|
| 0—5 | 提醒拒绝分享有效；不要求原谅或和解。 |
| 5—15 | 讲解复述不等于认同；回应可以是愿意、不愿意、需要时间或提出替代选项。只讲安全关系中的暂停。 |
| 15—25 | 讲师示范两种回应：“你想太多”与“你希望今晚有人听你说完，我理解对吗？”再示范做不到时不空口答应。 |
| 25—45 | 自愿角色演练：每人3分钟表达、2分钟复述、2分钟回应；互换需重新同意。旁听者勾选是否打断、评判、许诺或尊重拒绝。 |
| 45—50 | 形成一句暂停脚本和一个双方可接受的回谈时间；对方不同意则另议，不用沉默逼迫。 |

**关键话术**：“我现在难以好好听，想先暂停。若你愿意，我们明天晚饭后再用十分钟聊；你也可以另提时间。”

**检查与课后**：能复述并请对方校正，能坦诚回应，才算技能示范完成；不以对方最后答应为成绩。D6做一次小邀请，D7分别回顾第一周。若暂停后出现追逐、威胁或阻挡离开，停止双人练习并启动安全分流。

## 阶段过渡检查

进入第二阶段不要求情绪更亲密，但每位学员须理解可拒绝、可撤回、无惩罚；两人能独立表达愿不愿意尝试。任何一方不愿意，继续个人／非接触路径。不存在必须在D8升级到触碰的要求。
