# 第二阶段：身体感知与爱抚沟通（D8—D14）

U3从评判回到感觉含L05—L06；U4双方可选择的爱抚含L07—L08。每课50分钟。课堂全为非接触活动，不让讲师或学员对他人进行身体操作。家庭选做由本人决定，默认手／前臂或衣物外肩部、短时间、无升级任务；双方每次均可不参加。

## L05｜从“我表现得怎样”回到“我现在感觉怎样”

- **日程与目标**：D8，U3。能用中性词描述两种当下感官信息，知道“无明显感觉”和“不喜欢”同样有效。
- **材料**：普通杯子、布料或纸张任选其一，K05感官觉察卡；避免强香味、强光或必须入口的物品。
- **研究锚点**：E03—E04、E13；短练习是原创教育设计，不能等同正念治疗。

| 分钟 | 教学动作与讲师提示 |
|---|---|
| 0—5 | 允许睁眼、移动、不参加，不规定呼吸节奏。 |
| 5—15 | 区分感觉、偏好和评判：温暖是感觉，喜欢温暖是偏好，“我应该更有感觉”是要求。 |
| 15—25 | 讲师用物件示范：“我注意到表面粗糙；我暂时不确定是否喜欢。”不演示身体私密部位。 |
| 25—45 | 用K05：观察物件30—60秒，停下来记录，选择是否再试一次；不想触摸可只观察颜色与光线。交流只谈工具是否可用。 |
| 45—50 | 出口题：分辨三个句子属于感觉、偏好还是评判；自行选课后时长。 |

**关键话术**：“练习不是努力制造愉悦，而是给真实反馈一个位置。”

**检查与课后**：能描述或明确说无感即可。D8只做个人练习2—5分钟，加简短记录；不要求闭眼扫描全身。若内在觉察加重不适，改看外部物件或结束；不把这种反应诊断为创伤。

## L06｜身体变化、盆底与性感知：理解边界

- **日程与目标**：D9，U3。能区分一般教育与临床评估；能指出紧致、舒适、唤起和关系连接不是同一指标。
- **材料**：原创简化身体功能文字图、K06舒适地图、三个转介案例；无内部检查或器械。
- **研究锚点**：E08—E09支持审慎识读和个别化边界。

| 分钟 | 教学动作与讲师提示 |
|---|---|
| 0—5 | 提醒不需分享健康史或展示身体。 |
| 5—15 | 讲清盆底具有多种功能，训练不能只讲收紧；身体状态和性感知并非单一肌力问题。 |
| 15—25 | 案例辨析：疲劳时不想靠近；触碰出现持续疼痛；担心自己没有“足够性感”。分别选择休息沟通、医疗评估或非羞耻化教育。 |
| 25—45 | 个人填写K06，只标当日愿意／不愿意／不确定的非私密活动。另一项为写“就诊时我想问什么”；不做肌力或健康评分。 |
| 45—50 | 检查：哪些情况停止身体练习？谁可以作诊断？ |

**关键话术**：“舒服不是靠忍出来的。我们不从外观、收紧能力或一次体验判断你的身体价值。”

**误区与停止**：本课不教收缩次数、屏气、阴道负重、内部触诊、疤痕操作或用憋尿训练；也不建议停药。疼痛、异常出血、感染疑虑等转专业评估。产后／术后限制遵循原医疗团队意见，不用统一等待天数放行。

**检查与课后**：知识情景能分流即可，不要求身体动作。D9做舒适地图，D10做非接触的偏好表达。若地图也令人紧张，用活动清单代替。

## L07｜亲密爱抚能力：请求、反馈、调整、停止

- **日程与目标**：D11，U4。能把模糊“随便”变成可确认选择，能听到反馈后改变或停止。
- **材料**：K01、K06、K07反馈卡；用递杯子／调整座位等中性任务做课堂演练。
- **研究锚点**：E01—E03；具体反馈练习是原创课程工具。

| 分钟 | 教学动作与讲师提示 |
|---|---|
| 0—5 | 再次说明给予和接受两方都可以停，角色不由性别决定。 |
| 5—15 | 示范四步：具体邀请→明确答复→途中询问→按答复调整。边界是持续信息，不是一次签字。 |
| 15—25 | 案例：甲说“随便”，乙不猜测，给“现在不做／只聊天／以后再说”的选项。提醒不确定时先不触碰。 |
| 25—45 | 角色演练中性任务：说“更近一点／保持／换一种／停止”；接收者先回应再动作。观察者只记是否即时尊重，不记谁更主动。 |
| 45—50 | 每人写一条自己愿意使用的反馈句；可只交虚构版本。 |

**关键话术**：“这不是考核你会不会让我满意；我说更慢或停，是在提供信息。”“你说停，我们就停。”

**检查与课后**：听到停止后不争辩、不追加接触，才可通过情景技能检查。D11家庭作业只讨论允许的范围和停止词，不要求实际触碰。伴侣不参与则自己对着卡片练习。

## L08｜低压力触碰：体验、留白与复盘

- **日程与目标**：D13，U4。能说明家庭选做的安全流程，允许体验中性或不愉快，并在结束后无指责复盘。
- **材料**：K08家庭练习卡、K11每日记录；课堂仅用文字或自己的衣袖／物件示意，不示范学员接触。
- **研究锚点**：E03；本版不使用“感官聚焦治疗师”称谓，不复制临床进阶协议。

| 分钟 | 教学动作与讲师提示 |
|---|---|
| 0—5 | 判断今天适不适合：自由意愿、可停止、无相关不适、私密安全环境。任一不满足转非接触版。 |
| 5—15 | 讲解家庭流程：各自决定→约定部位和时间→短暂尝试→询问→结束→分别复盘。没有增加强度或扩大部位的任务。 |
| 15—25 | 案例：接受者中途笑但说不舒服。正确回应是停止确认；不以笑、关系身份或身体反应否定拒绝。 |
| 25—45 | 用纸卡排流程、辨认错误，模拟语言。若场地无法保障隐私或存在情绪压力，不布置双人身体作业。 |
| 45—50 | 讲师逐项确认理解：停止是否无需理由？拒绝是否无惩罚？能否只选观察物件？ |

**家庭选做**：双方同意后仅手、前臂或衣物外肩部；先30—60秒，停下来各自决定是否继续，总触碰时间不超过本卡建议5分钟。时间为保守试教设计，不是有效剂量；更短、零触碰均有效。无需互换角色。没有作业外继续任何活动的义务。

**检查与课后**：完成定义是理解并自主选择，不能用有没有兴奋或愉悦打分。不收照片、视频或具体身体细节。D14回顾压力、边界和负担，不按打卡催促补课。若发生越界或痛苦，停止相关任务，按09处理后再决定是否适合继续。

## 阶段过渡检查

每人独立回答：拒绝是否被尊重？练习是否增加压力？是否还愿意继续？对方无法安全看到的回答不得在伴侣之间共享。任何安全疑虑优先处理；不能用双方平均满意度放行第三阶段。
