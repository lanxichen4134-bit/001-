# 课程效果评估与试点判定

第一轮先回答“能否安全、可接受地交付”，再探索“哪些体验可能改变”。本专题尚未开展试点，以下全部是预先拟定的方案，没有参与人数、改善率、满意度或销售数据。没有对照组的前后变化不能归因于课程。

## 评价层次与指标

| 层次 | 指标 | 方法与解释 |
|---|---|---|
| 试点主要：安全 | 越界、压力、疼痛、不良情绪反应、隐私事件及处理 | 07安全单列＋自愿事件报告；独立处理，不与满意度相抵 |
| 试点主要：可行性 | 入组、学习负担、选择路径、退出、问卷响应、支持工作量 | 用真实分母与流程记录；不以触碰完成率作成功指标 |
| 学习成果 | 8题知识理解、虚构场景5项技能 | 个人前后与观察；题目熟悉度与评分者偏倚需披露 |
| 探索性主要体验域 | 情感连接E、身体感知与舒适B | 使用CE-12各域均值与有效题数；不是已验证结局工具 |
| 探索性其他体验 | 共同协作R、C10/C11压力、C12兴趣 | 各自报告，不合成关系健康总分 |
| 可持续性 | D42仍自愿使用哪些方法、是否有延后不适 | 不把继续练习等同关系改善 |
| 产品可用性 | 哪些内容有帮助／负担大、语言理解、愿意支付的条件 | 与关系效果分开，不用付费或推荐意愿证明疗效 |

不采集性生活次数、高潮次数或身体私密照片作为默认指标。若未来有充分研究理由收集额外信息，须独立论证必要性、许可和保护，不在本版顺便扩张。

## 时间点与负担

| 时点 | 内容 | 预计负担（待实测） |
|---|---|---|
| T0／D1学习前 | 知情说明、独立适配确认、CE-12、8题知识、自选目标 | 8—12分钟 |
| T7 | CE-12、5项安全提示、负担与选择路径 | 4—6分钟 |
| T14 | 同T7，检查是否需要降级／暂停 | 4—6分钟 |
| T21 | CE-12、安全、知识、可选技能场景及开放反馈 | 8—12分钟 |
| T42 | CE-12、安全、仍使用的方法与延续选择 | 5—8分钟；另行自愿联系 |

统一回顾过去7天；不能把T42误写成从D21以来累计。调查日程可按个人调整，记录实际日期，超出目标日±3天者注明窗口偏差，不补造准时数据。每次联系须在本人许可的安全时段与渠道进行。

## 分母和缺失怎样处理

1. 流程报告：咨询者、愿意接受适配说明者、符合项目条件者、实际报名者、开始学习者、各时点响应者分别计数。安全分流不算“拒绝配合”。
2. 单人版与伴侣版分开；伴侣版同时报告对数和人数，例如N对／2N人，不能把两人当完全独立样本。
3. 缺失、拒答、不适用和退出分别编码；不把缺失填0、不把退出视为无效学员剔除后只报好结果、不用末次观测填补全部后续。
4. 前后比较使用同一人共有有效题，按07计分；仅有一方数据的伴侣保留个人结果，不能给整对关系下结论。
5. 分别描述双方都改善、一方改善一方下降、双方下降、资料不足；不把同一对的平均提高作为两人都受益。
6. 小样本重点报告人数、比例及分母、分布和不确定性。需做置信区间时由统计人员选方法；均值变化不能标为临床显著。未来正式对照研究采用伴侣聚类／多层模型或合适的双人分析。

## 预先拟定的试点决策规则

以下阈值是运营讨论起点，不是已验证常模。招募前锁定最终版本，不能看见结果后改门槛。

| 判定 | 触发条件 | 动作 |
|---|---|---|
| 立即暂停相关活动 | 任何疑似课程诱发的强迫、拒绝后继续、严重身体伤害或重大隐私泄露 | 先保障安全，独立专业复核；不等待统计显著性 |
| 个体暂停与适配 | 疼痛、明显不适、压力上升、难以自由拒绝或本人要求 | 停相关任务，转非接触／退出／专业支持；不自动视为必须退全部课程 |
| 修改交付后再试 | 超过约1/4已响应者认为负担过高，或T21响应不足约70%，或关键安全知识反复误解 | 查看具体人数、退出原因与未响应偏倚；缩短、拆分或重写，不直接扩大招生 |
| 可以考虑下一轮 | 无未解决严重事件，回应渠道有效；多数人能理解选择权，学习负担可承受，资料足以判断可行性 | 仍只称可行性信号，不称安全性已证明或效果确立 |

“没有事件报告”可能是没发生，也可能是不敢说、渠道不安全或失访；报告须讨论这些替代解释。C10/C11任何明显个体上升均可触发自愿核对，不需达到统计阈值；不能用分数诊断风险。

## 第二阶段效果研究建议

第一轮修订后，如需评价疗效或作较强市场宣称，应与合格研究团队合作：确定可验证的主要结局与中文工具；预注册假设、分析、停止及缺失方案；按合理效应和伴侣内相关性计算样本量；考虑一般关系教育主动对照、等待组的伦理与局限；记录同期治疗、重大生活事件及依从性；由尽可能独立的评估者处理资料。

不能直接复用其他项目的效应量为本课估算“有效率”。研究对照不应剥夺正常医疗或安全服务。需要伦理审查的研究先按实际机构要求完成；本方案不自称伦理批准。
