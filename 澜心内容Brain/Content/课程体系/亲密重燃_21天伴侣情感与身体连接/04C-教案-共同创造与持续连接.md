# 第三阶段：共同创造与持续连接（D15—D21）

U5欲望差异与共创含L09—L10；U6修复与延续含L11—L12。每课50分钟。连接可以是陪伴、谈话、共同活动或可选触碰，不以性行为进阶为方向。继续遵守双方独立同意、课堂非接触和所有退出路径。

## L09｜欲望不同步时，怎样保留彼此的选择

- **日程与目标**：D15，U5。能区分欲望、意愿、身体反应和行为；能讨论差异而不指定“问题方”。
- **材料**：K09亲密菜单、Q3／Q5／Q7知识题；虚构日程冲突案例。
- **研究锚点**：E02、E11；回应性欲望是解释路径，不是要求先参与的理由。

| 分钟 | 教学动作与讲师提示 |
|---|---|
| 0—5 | 提醒个人版和跳过选项；不询问性生活次数。 |
| 5—15 | 用四张词卡区分“想要、愿意、身体反应、做了什么”，说明它们不总一致。 |
| 15—25 | 案例：甲想拥抱，乙想独处；或甲想约会，乙疲惫。辨析为什么“各让一步、勉强一次”不能替代自由同意。 |
| 25—45 | 各自写三项今天可考虑的连接、一项不愿意、一项不确定；自愿交换可分享部分，寻找交集。允许交集为空。 |
| 45—50 | 出口话术：如何在对方拒绝后表达自己的失落，同时不施压？ |

**关键话术**：“我有一点失落，但尊重你今天不想做。我会照顾自己的情绪，我们可以另找合适的连接方式。”

**检查与课后**：能承认差异、不羞辱、不讨价还价、不把婚姻当义务；D15制作菜单，不安排性任务。长期困扰、疼痛或心理影响明显者转专业评估。

## L10｜让靠近有条件发生：共同时间、负担与好奇

- **日程与目标**：D16，U5。能共同调整一项现实负担，并设计低成本、可撤回的小活动。
- **材料**：K09菜单、空白分工表；不采集收入、消费记录或家庭隐私。
- **研究锚点**：E05—E06间接依据；现实分工参见既有总纲第13章。新鲜活动的具体剂量和效果为本课待验证假设。

| 分钟 | 教学动作与讲师提示 |
|---|---|
| 0—5 | 今天不要求浪漫消费；照护和准备不默认交给女性。 |
| 5—15 | 解释时间、睡眠、心智负担和空间是可讨论的条件，不能单靠“更性感”解决。 |
| 15—25 | 案例：一方安排全部约会细节，另一方只出席。区分提议、计划、执行、收尾四种任务。 |
| 25—45 | 设计一次10—20分钟共同活动：各自愿意、预算可承受、准备和收尾有人承担、能取消。列备用方案，例如一起听一首歌或各自休息。 |
| 45—50 | 检查每个人是否只承担自己自由同意的部分；不以对方同意为考核结果。 |

**关键话术**：“一起创造连接，也包括一起承担让它发生的准备工作。”

**检查与课后**：计划包含双方选择、任务归属和取消权即可。D16约定分工，D17可实施小活动或休息；不要为惊喜隐瞒触碰、第三人参与或其他影响同意的安排。

## L11｜没感觉、没做成、起了争执之后，怎样修复

- **日程与目标**：D18，U6。能区分普通失配与越界，练习承担具体行为责任，允许对方不接受修复邀请。
- **材料**：K10修复卡、09分流情景；只用低冲突虚构案例。
- **研究锚点**：E05为关系教育方向；E10支持安全优先，不能泛化为共同修复暴力。

| 分钟 | 教学动作与讲师提示 |
|---|---|
| 0—5 | 说明原谅不是作业，接触不能用来结束争执。 |
| 5—15 | 普通失配：忘记约定、疲惫、误会；越界：拒绝后继续、报复、威胁、强迫。两者走不同路径。 |
| 15—25 | 案例：甲不断问“有没有感觉”，乙感到压力。示范承担行为：“我刚才追问了几次，增加了压力，我会停止。”不加“但你也……” |
| 25—45 | 练习暂停→承认行为→询问需要→提出可拒绝的新安排；旁听者指出有没有讨要原谅或把责任转回对方。 |
| 45—50 | 出口题：何时不再用修复卡，而应停止共同任务并寻求安全支持？ |

**关键话术**：“你不需要现在回应或原谅。是否还要谈，由你决定。”

**检查与课后**：能识别越界、不对责任作对称分摊；D18写卡，D19可做低冲突谈话或只留给自己。若有控制或暴力，不把卡交给施害者作为对质材料，按独立安全支持流程处理。

## L12｜把21天变成自己的选择：延续与结束

- **日程与目标**：D20，U6。能比较自己的目标与体验，制定可取消的两周延续计划；理解没有性结果也可以结束课程。
- **材料**：K12延续卡、07复测入口、课程投诉与求助渠道。
- **研究锚点**：E05、E13只提供持续观察的研究启发；本课维护计划未验证。

| 分钟 | 教学动作与讲师提示 |
|---|---|
| 0—5 | 提醒结束不等于毕业证明、伴侣治疗成功或销售邀约。 |
| 5—15 | 回顾六项能力：选择、觉察、表达、回应、协作、求助；把过程体验与关系结果分开。 |
| 15—25 | 示例三条同样可接受路径：继续短练习；只保留聊天；暂停并求助。说明未来变化不应一律归功或归咎课程。 |
| 25—45 | 各自写保留一项、停止一项、需要支持一项；双方愿意时协商两周安排。定复查日与取消方法，不设身体进阶任务。 |
| 45—50 | 说明D21匿名/私人反馈与D42回访均可拒绝，不影响课程权益。 |

**关键话术**：“你可以保留有帮助的部分，也可以决定这不是适合自己的方式。”

**检查与课后**：计划写清个人选择、双方负担与停止条件，不用“保证重燃”表达。D21独立复测和课程反馈；讲师不得把低分解释为学员不够开放，不用复测结果推销高价治疗或私教。
