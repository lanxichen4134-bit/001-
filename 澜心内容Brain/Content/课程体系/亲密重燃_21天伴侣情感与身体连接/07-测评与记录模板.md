# 可复用测评与记录模板

这些模板用于教育反馈和试点，不用于诊断、选伴侣、判断谁有问题或证明疗效。**没有临床分界值，没有合格线，没有“关系健康总分”。** 所有题目可跳过；缺失不是零。填充表含敏感信息，只存报名时明确同意的受控位置，绝不提交公开仓库。

## A｜独立参与与安全确认（报名及每次需要时）

每位学员在安全私人渠道自行判断；不由伴侣代填、不共同核答案。先确认当前设备、消息和填写场合是否安全；不安全则不填写、不自动发送提醒。可仅请求一次私下沟通，不必书面披露原因。

| 提示 | 可选答复 | 后续动作 |
|---|---|---|
| 我是年满18岁的成年人，理解课程不是治疗 | 是／否／暂不答 | 否则不进入本课程；暂不答先补知情说明 |
| 报名和每次练习是我自己愿意的 | 是／否／不确定／暂不答 | 否或不确定：暂停共同任务，独立沟通 |
| 我能拒绝或退出，而不担心惩罚、威胁或报复 | 是／否／不确定／暂不答 | 否或不确定：安全负责人私下支持，不共同练习 |
| 目前有身体不适、恢复限制或强烈反应，使触碰练习不合适 | 是／否／不确定／暂不答 | 是或不确定：先非接触路径，需要时专业评估 |
| 我知道如何安全联系课程负责人／独立投诉渠道 | 是／否 | 否：先提供并核对渠道，不进入身体选做 |

拒答不等于通过安全确认，也不自动被标为高风险。无法确认双人练习条件时，保留个人非接触路径，私下澄清是否适合继续；不以增加数据收集强行解决安全不确定。

## B｜连接体验自评 CE-12 v0.1（本课自建）

**说明**：回想过去7天，选择最贴近自己的情况。0=完全不符合，1=较少符合，2=部分符合，3=大多符合，4=非常符合；另有“不适用”“不愿回答”。双方各自回答，分数默认不向伴侣共享。不是标准化心理量表。

| 编号 | 题目 | 领域 |
|---|---|---|
| C1 | 我感到伴侣愿意认真听我表达。 | 情感连接E |
| C2 | 我感到自己在关系中的需要被理解。 | 情感连接E |
| C3 | 我与伴侣有过符合我意愿的靠近或陪伴。 | 情感连接E |
| C4 | 我能辨认自己在靠近时舒服、不舒服或不确定的感受。 | 身体感知与舒适B |
| C5 | 在我自主选择的亲近方式中，我的身体总体感到舒适。 | 身体感知与舒适B |
| C6 | 我能说出希望保留、调整或停止的具体方式。 | 身体感知与舒适B |
| C7 | 我与伴侣能讨论彼此不同的亲密需要。 | 共同协作R |
| C8 | 连接所需的时间安排、准备和收尾得到了双方愿意的承担。 | 共同协作R |
| C9 | 在没有达成一致时，我们仍能尊重彼此的选择。 | 共同协作R |
| C10 | 我担心不配合亲密活动会让伴侣失望或生气。 | 亲密压力P，单项，越高压力越大 |
| C11 | 我觉得自己必须表现得有感觉、有兴趣或足够性感。 | 表现压力P，单项，越高压力越大 |
| C12 | 我对与伴侣进一步亲近有兴趣或期待。 | 吸引／兴趣A，选答单项 |

**计分**：E=有效C1—C3均值；B=有效C4—C6均值；R=有效C7—C9均值，各域至少2项有效才计算，并报告有效题数。C10、C11、C12分别呈现，不反向并入总分。未发生相关活动可选不适用，不算0分；个人版可填感知／压力项，伴侣相关不适用者不生成虚假的关系得分。

**前后比较**：同一人同一领域使用两时点共有的有效题，至少2题才计算可比变化；否则写“不可比”。只作描述，不将±1分等任意变化称临床显著。跨人的均值不能隐藏一方下降，个人与伴侣组分别报告。

## C｜安全与负面体验单列（T7／T14／T21／T42）

回答：有／无／不确定／不愿答；可只请求联系，不书写事件。

- S1 过去7天，是否有你说不、停或不确定后，练习仍继续的情况？
- S2 是否出现与课程有关的催促、责备、报复或你担心安全的情况？
- S3 是否出现练习相关疼痛、明显不适或持续情绪困扰？
- S4 是否担心自己的信息被他人看见或分享？
- S5 是否想通过你指定的安全方式获得独立支持？

“有”或“不确定”需要按[09流程](09-讲师规范与安全转介.md)由负责人及时独立回应，不在伴侣面前确认；不计入任何改善总分。自报“无”也不能证明绝对安全。表单必须写明监看时段和紧急渠道，不能让学员误以为实时求助系统。

## D｜知识与情景判断（8题，教育检查）

每题选对／错／不确定，可使用文字或口头版本。T0与T21同题会有记忆效应，应在评估中披露；后续另建等难度版本须再次试测。

| 题号 | 判断句 | 讲师答案与简释 |
|---|---|---|
| Q1 | 已婚并且过去同意过，今天就无需再确认。 | 错；同意具体且随时可变。 |
| Q2 | 一方中途说停，另一方应立即停止，不要求补偿。 | 对。 |
| Q3 | 身体出现唤起反应，就证明愿意继续。 | 错；反应不是同意。 |
| Q4 | 练习出现疼痛，可以加大力度试着突破。 | 错；停止相关活动，必要时专业评估。 |
| Q5 | 欲望不同，较低欲望的一方就应接受更多训练。 | 错；差异需要协商与适配，不能指定问题方。 |
| Q6 | 图式可以作为理解方式之一，但不能据此诊断对方或决定童年因果。 | 对。 |
| Q7 | 这套21天课程已经被文献证明能够恢复激情。 | 错；本课程尚待直接验证。 |
| Q8 | 存在威胁、控制或报复时，应先停止共同任务并寻求安全支持。 | 对。 |

答对数／实际回答数分别记录；不确定计未掌握，拒答标缺失。Q1—Q4和Q8是关键理解点，未掌握时补充说明并用新情景复述，不以分数羞辱或强迫身体练习。

## 复用与校验限制

CE-12可按本课原样试用，但更改文字、语言、回顾时间或计分必须改版本，不与旧分数直接混比。先做理解访谈，再评估内容效度与负担；小样本不能证明信效度。未来如选CSI等成熟工具，须另核中文验证、许可和适用条件，不能复制网上题目便称标准化。原有“女性身体状态测评1.0”不用于诊断伴侣关系或替代本课安全流程。
