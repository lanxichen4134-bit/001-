# 产品化与试点方案

当前建议先做小规模教育试点，确认边界、负担与参与意愿，再决定正式产品形态。以下人数、节奏与配置均为AI研发建议，不是用户已确认的经营计划、承诺价格或已完成招生。

## 产品结构

| 层级 | 交付内容 | 承接边界 |
|---|---|---|
| 公开体验课（可另开发） | 60分钟：连接困扰→同意→一个非接触倾听练习→课程适配说明 | 不做现场触碰，不用关系焦虑促销，不把公开课当诊断 |
| 21天个人学习版 | 同一知识主干、个人替代任务、手册与卡、可选答疑 | 明确不保证改变伴侣；个人与双人结果分开 |
| 21天伴侣版 | 12课、21天自选练习、3次答疑、独立支持入口、T0—T42评价邀请 | 双方独立同意，不以一方付费代替另一方报名 |
| 三天两夜线下选配 | 下面的全新工作坊设计，复用原课程材料 | 不是历史课表复刻，不包含私密接触示范或临床治疗 |
| 专业支持 | 外部合格医疗、心理或安全服务 | 作为独立转介，不包装为课程升级销售 |

主课录播单课建议25分钟知识＋20分钟非接触练习＋5分钟复盘，12课共约10小时；3次60分钟答疑另计。加每日10—15分钟任务，总负担可能约16.5—18.25小时／21天（部分复盘可合并，实际待测）。这对忙碌伴侣可能偏重，首轮必须记录真实耗时；若负担过大，将每课分成两个短段、减少重复记录或延长学习窗口，不催促追赶。

## 试点分四步

**P0：内容与安全审查。** 由业务负责人、相应医疗／心理顾问及安全负责人逐项审查03、04、07、09；核具体人员、当地转介、隐私告知和退款退出政策。用户本次授权完成研发及提交，不等于本稿通过专业审核或启动招生。

**P1：理解与工作人员试教。** 建议4—6名自愿成年人分别阅读说明并反馈词语理解；先用虚构情景、不采私密经历、不安排触碰。重点检查“爱抚、回应性欲望、停止、双方责任、非治疗”是否被误解。该轮是认知访谈与可用性检查，不能报告有效率。

**P2：小样本交付。** 建议10—12对自愿伴侣，另设4—6名单人学习者用于观察个人版适配；两组不是随机对照，不相互比较疗效。每人独立适配；允许退出和转非接触。每周一次可选答疑，问题预先去识别化。安全负责人不以招生和完课指标考核。

**P3：T42回访与决策。** 按10文件公开真实分母、失访、负担、不同步结果与负面反馈；修订后才决定第二轮。不把小试点命名为“临床验证”，不以满意度取代安全与连接结果。

P0—P3只是本产品开发步骤，不是仓库的内容状态、研究证据等级或小红书B1/B2/B3。这里没有新增评论研究；真实需求研究未来按仓库既有流程另行执行。

## 人员、交付物与时间安排

| 环节 | 责任角色（人员待指定） | 可检查的交付 |
|---|---|---|
| 专业与内容审核 | 主讲＋相应专业顾问 | 每项“通过／修改／不可讲”记录及版本 |
| 安全与运营准备 | 安全负责人＋运营 | 独立渠道、值守时间、紧急流程、转介名录与退出告知 |
| 教材制作 | 主讲＋编辑 | 12课讲义、字幕、可访问的手册与卡；AI辅助内容审校 |
| 招募与适配 | 独立适配人员 | 双方同意与路径选择，不收无关健康史 |
| 教学交付 | 主讲＋助教 | 出勤／选做／跳过分开，问题与修改记录 |
| 评估复盘 | 评估员＋负责人 | T0/T7/T14/T21/T42汇总、负面结果、改版决定 |

先用相对周排程：准备2周→理解试教1周→修订1周→21天交付→再过21天随访。实际日历、招生渠道和负责人尚未确定，不创建自动任务、不自动联系学员。

## 三天两夜选配：原创可行性草案

继承旧课程的集中学习启发，但本次未取得同名官方课表，以下不是旧课程复刻。每半天约2.5小时，含至少一次休息；晚上不安排身体进阶。住宿独立自愿，房间安排和退出须尊重各自选择。

| 时段 | 内容 | 产出与边界 |
|---|---|---|
| 第一天上午 | 安全与同意、连接目标、课程适配 | K01；全程非接触 |
| 第一天下午 | 事件／解释／需要、倾听角色演练 | K02—K04；虚构情景优先 |
| 第一晚 | 自愿写作、安静休息；无必须参加的夜课 | 不用“突破”或疲劳状态施压 |
| 第二天上午 | 身体感知与盆底识读、求助边界 | K05—K06；不做身体检查 |
| 第二天下午 | 请求、反馈、停止的语言演练；家庭选做说明 | K07—K08；现场不组织身体接触 |
| 第二晚 | 可选轻松公共活动或个人休息 | 无私密展示、无强制搭档或酒精促同意 |
| 第三天上午 | 欲望差异、现实负担、共同连接菜单 | K09；不设性目标 |
| 第三天下午 | 修复边界、个性化延续与安全反馈 | K10—K12；只与21天主课程引用联动 |

集中版不要求三天完成21天的所有任务；后续仍由学员自行选择。不能声称集中体验优于分散学习，需另测疲劳、理解、成本和负面反应。

## 招生与传播的可用文案边界

可用表达：“在21天里，学习表达需要、尊重边界，并在双方愿意时练习舒适的亲密爱抚，让日常多一些可以选择的连接。”

不可用表达：保证挽回、保婚、治疗性冷淡、修复创伤、提升高潮率、让伴侣上瘾、女性改变即可解决婚姻。不能把选择不接触的人排除出“成功案例”。

若制作短视频，优先一个生活问题：拒绝后如何继续保留连接；没有感觉如何不自责；如何把安排亲密的负担分给双方。它们目前是策划假设，不是已验证流量题。抖音、小红书、视频号的具体账号和现行平台规则本轮未核，不声称已可发布。
