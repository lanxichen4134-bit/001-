# 女性身体健康｜用户提问型选题资产

## 定位与使用方法

这是“身体的主人”支柱下的一组窄范围选题资产：将本次已明确的 20 个用户提问原样保留，并补充用于制作的场景、需求、潜在承接方向与风险提示。它不是新的全 IP 选题总库，也不替代旧 Obsidian Vault 的主选题库和专业子库。

所有“场景、背后需求、可承接方向”均为 **AI整理｜待通过后续真实用户研究继续验证**，不可表述为已验证的高频用户事实。制作前仍须补足可靠论据、确认具体产品与平台边界。

## 总体内容路径

```text
生活里的具体场景
→ 用户自己的提问
→ 一个可理解的身体感受或误区
→ 安全、有限的专业解释
→ 低压力的小观察或行动
→ 需要时，再连接系统训练、课程或合格评估
```

这些问题的优先级来自本次共创对“解决方案需求”的判断，不等于已经验证的流量预测或用户规模。先用安全科普、评论区收集与经授权的用户研究验证真实语言、问题排序与承接意愿，再决定内容规模化。

## 制作前检查

1. 每条内容只回答一个核心问题，不把盆底、激素、情绪、性、呼吸、核心和人生状态混为一个结论。
2. 先说具体生活场景与感受，再做有限、通俗的解释；专业术语放在解释层，而非标题层。
3. 区分可靠科学事实、合理推测、个人体验与待验证用户洞察；未核验时标注待核。
4. 不诊断、不开药、不替代正规医疗；不承诺治愈、恢复或人人有效。
5. 对持续疼痛、明显坠胀、异常出血、感染征象或明显排尿排便问题，建议寻求合格专业人员评估。
6. 不制造身体、年龄、性或亲密关系羞耻；不以恐惧、低俗擦边或过度营销促成转化。
