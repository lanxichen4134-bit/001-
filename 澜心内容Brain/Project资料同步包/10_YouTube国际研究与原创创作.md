# YouTube 国际研究｜用国际材料提出更好的问题

**从一句话开始：**“研究 YouTube 上女性盆底和围绝经的视频，看看哪些值得我讲、哪些适合备课。”执行者从[总览与已有批次](https://github.com/lanxichen4134-bit/001-/blob/main/%E6%BE%9C%E5%BF%83%E5%86%85%E5%AE%B9Brain/Content/%E7%A0%94%E7%A9%B6%E8%B5%84%E6%96%99/YouTube%E5%9B%BD%E9%99%85%E7%A0%94%E7%A9%B6/README_YouTube%E5%9B%BD%E9%99%85%E4%BC%98%E8%B4%A8%E5%86%85%E5%AE%B9%E7%A0%94%E7%A9%B6%E6%80%BB%E8%A7%88.md)查重，读 Brain/03、04、05、07、09、[选题SOP](https://github.com/lanxichen4134-bit/001-/blob/main/%E6%BE%9C%E5%BF%83%E5%86%85%E5%AE%B9Brain/Docs/LANXIN_TOPIC_SOP_V1.0.md)和[报告标准2.2](https://github.com/lanxichen4134-bit/001-/blob/main/%E6%BE%9C%E5%BF%83%E5%86%85%E5%AE%B9Brain/Docs/RESEARCH_REPORT_STANDARD.md)，自动填写本轮目标、受众场景、优先主题、路线、计划与上限、可用环境和停止点。指定账号不是授权无限采集。只查最影响正确性的缺口，其他工作并行推进。

YouTube 帮助理解国际表达、专业知识与课程结构；[小红书](https://github.com/lanxichen4134-bit/001-/blob/main/%E6%BE%9C%E5%BF%83%E5%86%85%E5%AE%B9Brain/Docs/XIAOHONGSHU_TOPIC_RESEARCH_REFERENCE_V1.0.md)帮助观察中国受众处境。两者可支持同一问题，证据各自标注；海外流量不代表中国女性需求，中国评论也不证明专业观点。YouTube 不套用小红书的 B1/B2/B3、预算或统计。自己的素材仍可直接进入共创。

## 来源、发现与两条路线

- **来源角色 A 专业、B 表达、C 讨论**是用途，可多选但逐项给证据；与下述路线 A/B 无关。按频道 ID 与创作者矩阵去重；单个讲者以其具体主张的资质、机构、利益关系和外部证据核验，频道认证仅说明身份信号。个人体验、广告、机构科普、访谈嘉宾观点、指南分开。受众是频道可见定位或研究假设，无法得知实际人口构成时写未知。
- 同时从已核频道和主题词找视频；用专业术语＋用户生活语言组合，例如 pelvic floor relaxation / can't tell if I'm doing Kegels、perimenopause / what to tell my doctor、relationship repair / can I say no、interoception / noticing bodily signals。记录实际查询、入口、日期、排序、可见范围、重复与取舍；搜索和推荐流可能个性化，先收机构来源再加入反例。优先近期，允许仍有价值的旧作品并注明时效。
- **路线 A：≤10:00**，普通视频和 Shorts 分开。研究公开传播、内容解释、表达设计与评论；选题需要自己的中文问题、可靠依据和独立表达。
- **路线 B：>10:00**，优先 30–120 分钟的讲座、深访和课程；10–30 分钟可作专题。先核讲者、层次、主张、教学组织、现行指南和证据局限。用章节问题拆解，不能按时长机械切稿；低播放不是淘汰依据。
- 首轮计划参考 A 30–50、B 8–15，合计深读 8–12。后续手动任务按目标填写，未另定时以本轮参考上沿作工作量上限，不为凑数扩题；评论先观察每条热门与最新各一段连续可见窗口，各最多 10 条主评论，必要回复另记，单视频合计不超过 30 个可见条目。只作研究抽样设计，并非平台授权。达到本轮约定上限、同源重复无新增、风险不可控、权限不清或无法读正文时停止相应路径；部分完成照实交付。

| 3 可靠回答 | 关键事实有可追溯支持；医学/心理主张核资质、适用人群、原证据、现行指南及替代解释。非专业内容解释何处不适用 |

## 网页、字幕、指标与评论

1. 先在可用浏览器打开官方频道、准确视频、简介及播放器；正常登录仅在需要时由本人完成敏感步骤，不索取或保存凭据。若浏览器或权限不可用，记录具体页面、步骤、现象和已尝试动作；可用发布者官网/同集正式文字补读，注明不是 YouTube 正文。官方 API 只是可选入口，须另有合规配置和访问权限；本框架不依赖 API 密钥或第三方下载器。遵守[服务条款](https://www.youtube.com/t/terms)、[API 开发政策](https://developers.google.com/youtube/terms/developer-policies)与访问限制；不用爬虫、隐藏接口或绕过流程。
2. 有字幕时从[官方逐字稿面板](https://support.google.com/youtube/answer/15930243)或获许可的同集稿件阅读。记录语种、轨道（作者提供／自动生成／未知）、实际区间、章节链接与说话人；有必要回听关键术语和否定句。原文短摘、中文译文、AI 概述和歧义单列。简介章节时间只标“导航”，未读正文时不作引文定位。资料不足时明确只读了什么，不凭标题补故事、论证或结尾。
3. 每次追加带时区的观察：原发布日期、时长、类型、播放/赞/评论数、其他真实可见指标，精确值与网页约数分开。未显示／未取得不等于 0；零仅在明确显示时记录。[公开字段](https://developers.google.com/youtube/data/reference/rest/v3/videos)的 favoriteCount 不作收藏量；Shorts 观看按当时口径，2025-03-31 起开始播放或重播可计入，无最低观看时长。CTR、观看时长、留存与来源依[获授权分析](https://support.google.com/youtube/answer/9002587)取得，不反推。
4. 优先同频道、同格式、相近时长及发布年龄，记录窗口与纳入规则，尽量至少 5 条；不足就报样本不足。相对播放 = 对象播放 ÷ 可比中位数；赞播比、评播比只用同一次观察且分母非零，约数计算明确约值。比较时披露样本、发布时间差、可见性、付费推广未知、重发/剪辑关系。标题、封面、内容结构是观察；解释是假设；没有 CTR、留存或实验不能证明因果。
5. 评论窗口记录排序、日期、范围、是否展开、主评/回复、作者身份显示、去重及排除。分类：具体问题、体验、赞同、质疑、纠错、作者补充、推广/疑似重复。昵称不用于确认独立人，评论只证明有人这样表达，不能估计患病率、需求比例或中国受众。敏感经历、未成年人隐私、可搜索的用户引文及定位不进 GitHub；没有获准受控证据位就不留原文或评论定位，公开只写去标识化主题并说明回查局限。

# YouTube 中文报告与拍摄理解模板 1.0

配套：[执行规范](https://github.com/lanxichen4134-bit/001-/blob/main/%E6%BE%9C%E5%BF%83%E5%86%85%E5%AE%B9Brain/Docs/YOUTUBE_RESEARCH_V1.0.md)、[报告标准2.2](https://github.com/lanxichen4134-bit/001-/blob/main/%E6%BE%9C%E5%BF%83%E5%86%85%E5%AE%B9Brain/Docs/RESEARCH_REPORT_STANDARD.md)。沿用三层阅读顺序；YouTube 的类型、时间、评分和评论口径以专项规范为准。未取得的字段如实注明，不复制小红书统计。

## 第一层｜中文总览

用几段话回答：本轮真正发现了什么；哪类创作者长期追踪、哪类仅学表达；传播是否有可比优势；什么课程值得备课、什么说法不能照用；先拍什么、为什么和替代方向；证据上限及什么会改变判断。附逐条、证据与 Content 的导航，以及来源、评论、拍摄页、草稿、审核、同步的实际计数。报告完成与研究动作分列。

## 第二层｜每条重点视频（可独立阅读）

1. 原视频：标题、发布者、讲者及资质/利益关系、准确链接、语种、日期、时长、格式、观察时点、可见数据、实际读到的范围。
2. 内容：开头问题、展开过程、关键论证/案例、结尾，实际未读处明确。必要短摘按「轨道/说话人/真实时间码—原文—中文译文—术语歧义」，另列原创概述。
3. 评论：热门/最新窗口、主评或回复、问题/体验/赞同/反对/纠错/作者补充/推广及排除；有权限时在受控版显示必要短原文、译文、父评论与定位。公开只留允许的信息。
4. 价值：五门槛逐条写理由；按路线列分项证据与分数或未评。比较样本、表现与合理替代解释；传播、知识、原创各一句结论。
5. 问题：实际表达、反例、推测、未覆盖的人群与语境；标注本地需求证据是否存在。
6. 为什么适合澜心：具体 Brain、可靠回答范围与真实素材；没有实例/资质就不用。
7. 原创：一个核心问题、观众收获、与原片不同的讲法、备选及排除原因。
8. 风险：事实、讲者观点、文化解释、AI 解释、未知与推翻条件；拟用事实逐条找独立依据；抖音、小红书、视频号分别列条件与审核。
9. 去向：共创／课程知识线索／观察／待补证／排除，以及补证后可以推进到哪一步。

课程另列：原始章节/时间位置、讲者身份、本轮读取范围、结构和概念、专业证据强弱及局限、课程主位置与拟用单元、可独立研究问题、版权范围；未读部分不当课程已吸收。

## 第三层｜证据附录

| 记录 | 最少可复核信息 |
|---|---|
| 批次与检索 | 日期时区、任务范围/上限、平台和环境、精确关键词及页面排序、实际查看范围、停止条件 |
| 账号与视频 | 频道 ID/handle、矩阵、语言与地区依据、最近可见作品、用途与排除原因；视频 ID、版本与原出处、路线 |
| 观察 | O 编号、观察时间、真实原值/约数、比较样本与计算；补观察追加 |
| 正文证据 | E 编号、已读区间、短摘/译文/概述类别、术语待核、页或时间定位、资料权利与保存范围 |
| 评论窗口 | W 编号、排序/起止、实际阅读及排除数、主评/回复/作者、偏差、合法受控回查位置（公开只留安全摘要） |
| 专业核验 | 拟用句、直接来源/版本/日期、适用对象、替代解释、专业审校人/状态 |
| 去向 | 五关、评分、下一步、Content ID 或课程主位置、试读和三平台状态、实际归档与跨端回执 |

## 每个原创选题的一页拍摄理解

用自然中文写给出镜者，附三个不同开头与一段骨架；完整口播放独立小节或同 ID 的独立版本，不混入研究正文。

- **在和谁说什么**：她处在哪个生活场景、遇到什么；原片真实讨论了什么、评论实际说了什么。AI 场景明确标示；证据不足则写未取得。
- **为什么由澜心讲**：对应已确认内容方向、可靠依据与独立理解；本条只讲哪个核心观点。
- **怎么把它讲明白**：三个开头各自解决什么；用哪个证据、可用故事或原创比喻；情绪从哪里进来、如何转向理解；结尾给什么选择。
- **拍前准备**：必要画面/物件/字幕或图示，示意与真实经历区别；资质、来源、平台、版权和专业审核待核。缺失关键条件就暂停相应版本。
