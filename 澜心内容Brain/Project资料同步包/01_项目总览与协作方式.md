# 项目总览与协作方式

## 这是一个什么项目

澜心内容 Brain 是一个长期内容操作系统。它的目标不是让 AI 批量生产内容，而是让灵感有入口、思想有沉淀、观点有来源、内容先共创、研究有边界，并让正式资产稳定留在 GitHub。

## AI 分工

- ChatGPT：思考、澄清观点、研究问题、内容共创与战略讨论。
- Codex：读取资料、维护文件、整理 Markdown、更新状态、执行 Git 闭环。
- Obsidian：澜心阅读、修改、搜索和重组资料的界面。
- GitHub：正式版本事实源。

## 默认内容共创流程

~~~text
灵感 → 讨论 → 真正观点 → 为什么值得讲 → 用户为什么需要
→ 澜心真实体验/故事 → 冲突或反常识点 → 选题
→ 三个开头 → 内容结构 → 澜心确认 → 完整稿件 → 发布 → 复盘
~~~

只有澜心明确说“直接写”“出完整文案”或“生成逐字稿”时，才跳过部分讨论。

## 原话与长期事实

- 灵感刚出现时，速度优先，先保存原话，不要求当场分类。
- AI 理解、标题、标签和候选观点可以增加，但不能覆盖原话。
- 一次聊天不能自动升级为长期身份、价值观、经典观点或禁用表达。
- 发现新洞见时，AI 要说“建议写入 Brain”，说明理由并等待澜心明确确认。

## 内容状态

raw_idea → discussing → idea_clear → structure_ready → drafting → approved → published → reviewed

## 公开与隐私边界

项目 GitHub 远端目前为公开仓库。不要上传 Token、密码、聊天原文、语音、影像、学员/客户/家人身份信息、健康资料或未公开经营数据。
