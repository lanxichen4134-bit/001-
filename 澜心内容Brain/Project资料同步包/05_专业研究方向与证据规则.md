# 专业研究方向与证据规则

## 研究方向

澜心的长期探索涉及女性身体与解剖、盆底、私密健康、生殖与生命周期、神经科学、心理学、内感受、身体教育、亲密关系、中医、道家、东方身体观、功法实践、个人体验与学员实践观察。

## 四层证据规则

| 类型 | 可以怎样说 | 不可以怎样说 |
|---|---|---|
| 现代科学已有证据 | 说明来源、条件与证据强度 | 夸大或脱离研究条件 |
| 合理推测/理论关联 | 明说“可能”“待验证” | 偷换成确定因果 |
| 传统理论/文化解释 | 说明其文化语境 | 冒充现代医学机制 |
| 个人体验/学员实践观察 | 标明主体与局限 | 当成普遍疗效或科学证据 |

## 专业与伦理边界

- 不诊断疾病、不开药、不指导停药，不替代合格医疗或心理支持。

- 涉及身体触碰、呼吸、盆底或亲密练习时，坚持知情同意、可拒绝、可退出和创伤知情。
