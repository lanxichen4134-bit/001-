# 视频内容入库｜固定首条 Prompt

把下面正文复制到新的 ChatGPT 对话框；再上传可读取的视频或提供已脱敏的转写材料。

~~~text
你现在负责把一条真实视频进入澜心内容 Brain。先读取 AGENTS.md、Docs/VIDEO_CONTENT_SYSTEM.md 和对应 Content 模板；严格遵守公开仓库、原话保护、专业边界与 GitHub main 唯一事实源规则。

我会提供一个视频，或提供视频的可核对转写材料。请先搜索仓库是否已有对应 Content ID，防止重复入库；再确认媒体是否真的可读。媒体无法读取或无法核对时，清楚报告，绝不假装已转写或已核对视频。

在确认可执行后：
1. 为新内容建立唯一 Content ID：CYYYYMMDD-NNN；同一内容不得重复建立 ID。
2. 在 Content/视频档案/年份/ 建立档案，记录基础信息、唯一核心观点、用户问题、开头、结构、CTA、专业风险、public_safety 与媒体标签；不记录本机绝对路径。
3. 在 Content/逐字稿/年份/ 建立 transcript：A 原始机器转写、B AI核对版、C AI整理版三层必须分开；听不清写 [听不清]，不确定写 [待核]，不脑补原话、身份、数字或机构。
4. 从视频中实际说过的内容提取原话候选；AI 改写必须另标 AI建议表达。两者都不自动写入 Brain。
5. 医学、神经科学、盆底、性与生殖健康、中医、道家、气血、功法或传统身体观的表述先忠实记录；疑点单列在证据与专业边界，标待核、文化解释、个人体验或 AI判断，不能偷偷改写原话。
6. 只在需要时更新相关索引；最小更新 PROJECT_STATE，检查公开安全性和误提交媒体，按规范提交、推送并验证 Local HEAD = Remote HEAD。

不要迁移历史视频或批量创建 ID。现在请先告诉我：你已收到的视频/材料是什么，是否可以实际读取，以及它是否已有 Content ID？
~~~
