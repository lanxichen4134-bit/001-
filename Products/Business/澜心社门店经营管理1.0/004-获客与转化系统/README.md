# 004-获客与转化系统

> 状态：⚪ **待系统讨论**  
> 当前仅完成零散方向归档，尚无正式1.0方案。

## 已讨论/已有方向

### 公域获客
- 个人IP内容；
- 视频号、抖音；
- 周一至周五公域交付型早课；
- “元气女人气血营”；
- 以女性大健康/气血作为更适合公域传播的精准入口；
- 直播、短视频、主题内容作为长期信任入口。

### 私域与存量
- 现有线上会员导向门店；
- 私域用户到公域跟练、打卡，再回到线下服务；
- 老会员转介绍；
- 会员积分/等级/权益促进持续参与。

### 线下与合作渠道
- 周边社区与商圈；
- 异业合作；
- 女性健康主题活动/沙龙；
- 医疗机构或妇产相关合作资源；
- 成都地区城市共建与会员网络。

## 待建立的标准路径

> **看见澜心社 → 产生兴趣 → 留资/参与 → 体验 → 到店 → 建档 → 首次成交 → 入会 → 复购 → 转介绍**
