# 005-客户交付与服务系统

> 状态：🟡 **已有核心原则，待形成标准SOP**

## 已确认服务原则

- 不制造焦虑；
- 客户被理解，而不是被判断；
- 客户被帮助，而不是被推销；
- 化繁为简，只解决当下最重要的问题；
- 客户离店后也越来越会照顾自己；
- 每一次到店都应成为恢复、放松和幸福的体验；
- 专业调理只做客户靠自己难以完成的部分。

## 已讨论的服务闭环

> **预约 → 迎宾 → 健康沟通 → 评估 → 明确本次目标 → 项目交付 → 反馈 → 家庭建议 → 预约下一次 → 线上跟进**

## 三场景交付

### 线上陪伴
解决：**每天有人陪我做。**

### 居家养护
解决：**离开门店以后，我依然知道怎样照顾自己。**

### 到店调养
解决：**有些问题，我不需要一个人扛。**

## 已讨论的交付工具
- 健康档案；
- 首次评估；
- 阶段复评；
- 家庭主动健康动作；
- 健康教育；
- 社群/打卡；
- 定期回访。
