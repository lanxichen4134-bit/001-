# 007-数据与经营系统

> 状态：⚪ **待系统讨论**

## 已提出的核心经营理念

门店不能只看营业额，要看客户、产品、员工和现金流的质量。

建议未来重点关注：

### 客户数据
- 新客数；
- 活跃会员数；
- 沉睡会员数；
- 到店频次；
- 复购率；
- 续费率；
- 转介绍率。

### 产品数据
- 各项目销售额；
- 各项目交付次数；
- 毛利；
- 复购率；
- 满意度；
- 床位/房间使用效率。

### 员工数据
- 人效；
- 服务人数；
- 客单；
- 会员留存；
- 满意度；
- 转介绍贡献。

### 财务数据
- 营业额；
- 毛利；
- 固定成本；
- 人工成本；
- 房租；
- 获客费用；
- 净利润；
- 现金流。

## 已提出的核心指标候选

> **单个活跃会员年度贡献值（Annual Value per Active Member）**

该指标用于避免只追逐一次大额充值，转向经营稳定的年度会员价值。
