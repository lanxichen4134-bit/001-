# 002-用户与会员系统

> 状态：🔵 **当前主讨论系统**  
> 核心目标：从“卖卡”转向“持续陪伴一个女人的全年与长期关系”。

## 已讨论并认可的方向

### 核心用户
- 30+女性奋斗者；
- 同时承担健康、家庭、事业、子女等多重责任；
- 有一定消费能力，重视品质、成长和长期健康；
- 不喜欢恐吓式营销和强推；
- 愿意为专业、温度、真实效果和长期陪伴付费。

### 会员关系逻辑
> **了解她 → 陪伴她 → 帮助她形成健康习惯 → 解决阶段性问题 → 记录和见证变化 → 陪她进入下一个人生阶段。**

已确认原则：
- 会员不是第九个产品，而是一种长期关系；
- 会员价值不能只靠折扣和次数；
- 应包含健康档案、阶段评估、线上陪伴、居家方案、到店支持、成长连接与共建；
- 未来重点经营“活跃会员年度价值”和长期留存，而不是一次充值额。

### 已讨论会员层级方向
目前只形成框架，**尚未定稿**：
- 基础会员；
- 100位创始会员；
- 核心/铁杆会员；
- 城市共建/客户董事会；
- 使命伙伴/共建者。
