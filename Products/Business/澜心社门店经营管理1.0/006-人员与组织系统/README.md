# 006-人员与组织系统

> 状态：⚪ **待系统讨论**

## 已有角色假设

门店未来可能涉及：
- 店长；
- 健康顾问；
- 技术老师；
- 教练/课程老师；
- 前台/客服；
- 会员运营；
- 内容与活动支持。

## 已确认的组织原则

- 产品与服务标准不能由“员工个人会什么”决定；
- 所有员工统一理解战略定位与四体健康管理模型；
- 专业判断与销售动作应适度分开，避免销售绑架专业；
- 不以单次销售额作为唯一绩效标准；
- 后续绩效应纳入服务质量、会员留存、复购、转介绍等指标；
- 技师等级、操作费、指定服务费与晋升体系需要与交付等级挂钩。

尚未定稿，后续必须结合真实产品毛利和单店盈利模型后确定。
